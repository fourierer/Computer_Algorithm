# 1.两数之和 解题思路

## 问题分析

在数组中找到两个数使其和为 target，返回这两个数的下标。核心难点在于如何高效地查找"另一个数"——即 `target - 当前数` 是否存在。

## 解法一：暴力枚举（代码中已注释）

### 思路

双重循环枚举所有数对，逐一判断是否满足 `nums[i] + nums[j] == target`。

### 算法步骤

1. 外层循环 `i` 从 0 到 n-1
2. 内层循环 `j` 从 i+1 到 n-1
3. 若 `nums[i] + nums[j] == target`，记录 i、j 并返回

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 解法二：哈希表一次遍历（代码实际采用）

### 思路

用字典 `result_maps` 存储已遍历元素的值→下标映射。对每个元素计算 `diff = target - nums[i]`，若 diff 已在字典中，则直接得到答案；否则将当前元素加入字典继续遍历。关键在于边遍历边查表，一次遍历即可完成。

### 算法步骤

1. 初始化空字典 `result_maps = {}`
2. 遍历数组，对每个 `nums[i]`：
   - 计算 `diff = target - nums[i]`
   - 若 `diff` 在 `result_maps` 中，返回 `[result_maps[diff], i]`
   - 否则将 `result_maps[nums[i]] = i` 记录当前元素
3. 遍历结束未找到则返回空列表

### 复杂度分析

- 时间复杂度：O(n)，每个元素只需一次查找和插入
- 空间复杂度：O(n)，最坏情况下需存储 n-1 个元素
