# 100.相同的树 解题思路

## 问题分析

判断两棵树是否相同，需要同时满足：
1. 结构相同（节点位置一一对应）
2. 对应节点的值相同

**关键洞察：** 两棵树相同 ⟺ 根节点值相同 且 左子树相同 且 右子树相同，天然适合递归。

## 解法一：DFS 递归（推荐）

### 思路

同时遍历两棵树，在每一步比较当前节点：
- 两个节点都为空 → 相同，返回 True
- 一个为空一个不为空 → 结构不同，返回 False
- 值不同 → 返回 False
- 否则递归比较左子树和右子树

### 算法步骤

1. 若 `p` 和 `q` 都为空，返回 True
2. 若其中一个为空，返回 False
3. 若 `p.val != q.val`，返回 False
4. 递归判断 `isSameTree(p.left, q.left) and isSameTree(p.right, q.right)`

### 复杂度分析

- 时间复杂度：O(min(m, n))，m 和 n 分别为两棵树的节点数
- 空间复杂度：O(min(m, n))，递归栈深度最坏为较小树的高度

## 解法二：BFS 迭代

### 思路

使用队列同时遍历两棵树，每次取出一对节点进行比较，并将它们的子节点成对入队。

### 算法步骤

1. 初始化队列，将 `(p, q)` 入队
2. 当队列不为空时，取出一对节点 `(u, v)`：
   - 都为空则跳过
   - 一个为空则返回 False
   - 值不同则返回 False
   - 将 `(u.left, v.left)` 和 `(u.right, v.right)` 入队
3. 遍历完毕返回 True

### 复杂度分析

- 时间复杂度：O(min(m, n))
- 空间复杂度：O(min(m, n))

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS 递归 | O(min(m,n)) | O(min(m,n)) | 代码简洁，面试首选 |
| BFS 迭代 | O(min(m,n)) | O(min(m,n)) | 避免递归栈溢出 |
