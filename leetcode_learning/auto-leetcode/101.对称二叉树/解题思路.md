# 101.对称二叉树 解题思路

## 问题分析

判断一棵二叉树是否轴对称，即判断左子树和右子树是否互为镜像。

**关键洞察：** 两棵树互为镜像 ⟺ 根节点值相同 且 左树的左子树与右树的右子树互为镜像 且 左树的右子树与右树的左子树互为镜像。

这与 100.相同的树 非常相似，区别在于比较的方向：相同树是 `left-left, right-right`，对称树是 `left-right, right-left`。

## 解法一：DFS 递归（推荐）

### 思路

定义辅助函数 `check(p, q)` 判断两棵树是否互为镜像：
- 都为空 → True
- 一个为空 → False
- 值相同 且 `check(p.left, q.right)` 且 `check(p.right, q.left)`

主函数调用 `check(root.left, root.right)`。

### 算法步骤

1. 若 `root` 为空，返回 True
2. 调用 `check(root.left, root.right)`
3. `check(p, q)` 递归比较：
   - 都为空返回 True
   - 一个为空返回 False
   - 值相等 且 递归比较镜像子树

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树的高度（递归栈深度）

## 解法二：BFS 迭代

### 思路

使用队列，每次成对取出节点进行比较。初始时将 `(root.left, root.right)` 入队。

### 算法步骤

1. 初始化队列，将 `(root.left, root.right)` 入队
2. 当队列不为空时：
   - 取出一对节点 `(u, v)`
   - 都为空则跳过
   - 一个为空则返回 False
   - 值不同则返回 False
   - 将 `(u.left, v.right)` 和 `(u.right, v.left)` 入队（镜像顺序）
3. 返回 True

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS 递归 | O(n) | O(h) | 代码简洁，面试首选 |
| BFS 迭代 | O(n) | O(n) | 避免递归栈溢出 |
