# 102.二叉树的层序遍历 解题思路

## 问题分析

关键洞察：
- 层序遍历 = BFS 广度优先搜索，使用队列逐层处理
- 核心难点：如何区分每一层的节点，把同一层的值放在同一个子列表中
- 方法：在每轮循环开始时记录当前队列长度 `level_size`，刚好就是该层的节点数

## 解法一：BFS 队列（推荐）

### 思路

使用队列进行层序遍历，每次处理一整层：
1. 队列初始放入根节点
2. 每轮取出当前层的所有节点（数量 = `level_size`），将它们的值收集到一个子列表
3. 同时将每个节点的左右子节点入队，作为下一层

`level_size` 必须在循环开始时记录，因为在处理过程中队列长度会变化。

### 算法步骤

1. 特判：根节点为空则返回空列表
2. 初始化队列，放入根节点
3. while 队列不为空：
   - `level_size = len(queue)`，记录当前层的节点数
   - 循环 `level_size` 次，依次出队：
     - 收集节点值到当前层列表
     - 将左右子节点入队
   - 将当前层列表加入结果
4. 返回结果

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，队列最多存储一层的节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| BFS 队列 | O(n) | O(n) | 经典层序遍历，直观易懂 |
