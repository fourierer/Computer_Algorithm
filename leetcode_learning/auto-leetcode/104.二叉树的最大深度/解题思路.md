# 104.二叉树的最大深度 解题思路

## 问题分析

二叉树的最大深度 = 从根节点到最远叶子节点的最长路径上的节点数。

**关键洞察：** 树的最大深度 = max(左子树深度, 右子树深度) + 1，天然适合递归。

## 解法一：DFS 递归（推荐）

### 思路

递归计算左右子树的最大深度，取较大值加 1。递归终止条件：节点为空时深度为 0。

### 算法步骤

1. 若 `root` 为空，返回 0
2. 递归计算左子树深度 `left_depth`
3. 递归计算右子树深度 `right_depth`
4. 返回 `max(left_depth, right_depth) + 1`

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树的高度（递归栈深度），最坏 O(n)

## 解法二：BFS 层序遍历

### 思路

使用队列进行层序遍历，每遍历完一层，深度加 1。当队列为空时，遍历的层数即为最大深度。

**关键点：** 每次处理一整层（通过记录当前队列长度），而不是逐个节点处理。

### 算法步骤

1. 若 `root` 为空，返回 0
2. 初始化队列 `queue = [root]`，深度 `depth = 0`
3. 当队列不为空时：
   - 记录当前层节点数 `level_size = len(queue)`
   - 依次弹出 `level_size` 个节点，将它们的非空子节点加入队列
   - `depth += 1`
4. 返回 `depth`

### 复杂度分析

- 时间复杂度：O(n)，每个节点入队出队各一次
- 空间复杂度：O(n)，队列最多存储一层的节点，最坏情况（满二叉树最后一层）约 n/2 个节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS 递归 | O(n) | O(h) | 代码简洁，面试首选 |
| BFS 层序遍历 | O(n) | O(n) | 直观易懂，适合理解层序遍历模板 |
