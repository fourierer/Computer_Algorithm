# 105.从前序和中序遍历序列构造二叉树 解题思路

## 问题分析

给定前序遍历和中序遍历序列，需要还原出原始二叉树。

**关键洞察：**
- 前序遍历：`[根节点, 左子树..., 右子树...]`
- 中序遍历：`[左子树..., 根节点, 右子树...]`

前序遍历的第一个元素一定是根节点。在中序遍历中找到根节点的位置，可以将中序序列分为左子树和右子树两部分。递归地应用这个规律即可构建整棵树。

## 解法一：递归 + 哈希表优化（推荐）

### 思路

1. 用哈希表预处理中序遍历，O(1) 定位根节点位置
2. 递归函数接收前序和中序的左右边界索引
3. 每次取前序遍历左边界对应的值作为根节点
4. 在中序遍历中找到根节点位置，计算左子树节点数
5. 递归构建左子树和右子树

### 算法步骤

1. 构建哈希表 `index`：`inorder[i] -> i`
2. 定义递归函数 `myBuildTree(pre_l, pre_r, in_l, in_r)`：
   - 若 `pre_l > pre_r`，返回 None
   - 根节点值 = `preorder[pre_l]`
   - 在中序中定位根节点：`in_root = index[preorder[pre_l]]`
   - 左子树节点数 = `in_root - in_l`
   - 递归构建左子树：`myBuildTree(pre_l+1, pre_l+size, in_l, in_root-1)`
   - 递归构建右子树：`myBuildTree(pre_l+size+1, pre_r, in_root+1, in_r)`
3. 调用 `myBuildTree(0, n-1, 0, n-1)`

### 复杂度分析

- 时间复杂度：O(n)，每个节点构建一次，哈希表查找 O(1)
- 空间复杂度：O(n)，哈希表 + 递归栈

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 + 哈希表 | O(n) | O(n) | 最优解，哈希表加速定位 |
| 递归 + 线性查找 | O(n²) | O(n) | 每次线性查找根节点，效率较低 |
