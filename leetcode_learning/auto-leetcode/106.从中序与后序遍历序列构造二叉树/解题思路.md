# 106.从中序与后序遍历序列构造二叉树 解题思路

## 问题分析

给定中序遍历和后序遍历序列，需要还原出原始二叉树。

**关键洞察：**
- 中序遍历：`[左子树..., 根节点, 右子树...]`
- 后序遍历：`[左子树..., 右子树..., 根节点]`

后序遍历的**最后一个元素**一定是根节点。在中序遍历中找到根节点的位置，可以将中序序列分为左子树和右子树两部分。递归地应用这个规律即可构建整棵树。

**与 105 题的区别：**
- 105 题用前序遍历（首元素是根），先构建左子树
- 106 题用后序遍历（末元素是根），先构建右子树

## 解法一：递归 + 哈希表优化（推荐）

### 思路

1. 用哈希表预处理中序遍历，O(1) 定位根节点位置
2. 递归函数接收中序和后序的左右边界索引
3. 每次取后序遍历右边界对应的值作为根节点
4. 在中序遍历中找到根节点位置，计算左子树节点数
5. 递归构建右子树和左子树（注意顺序）

### 算法步骤

1. 构建哈希表 `index`：`inorder[i] -> i`
2. 定义递归函数 `build(in_l, in_r, post_l, post_r)`：
   - 若 `in_l > in_r`，返回 None
   - 根节点值 = `postorder[post_r]`
   - 在中序中定位根节点：`in_root = index[postorder[post_r]]`
   - 左子树节点数 = `in_root - in_l`
   - 递归构建右子树：`build(in_root+1, in_r, post_l+size, post_r-1)`
   - 递归构建左子树：`build(in_l, in_root-1, post_l, post_l+size-1)`
3. 调用 `build(0, n-1, 0, n-1)`

### 复杂度分析

- 时间复杂度：O(n)，每个节点构建一次，哈希表查找 O(1)
- 空间复杂度：O(n)，哈希表 + 递归栈

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 + 哈希表 | O(n) | O(n) | 最优解，哈希表加速定位 |
| 递归 + 线性查找 | O(n²) | O(n) | 每次线性查找根节点，效率较低 |
