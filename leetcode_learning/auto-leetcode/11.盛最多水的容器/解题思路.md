# 11.盛最多水的容器 解题思路

## 问题分析

容器的容量由两个因素决定：
1. **宽度**：两条线之间的距离（右指针 - 左指针）
2. **高度**：两条线中较短的那条（木桶效应）

因此，面积公式为：`area = min(height[left], height[right]) * (right - left)`

关键洞察：如果移动较高的那条线，宽度必然减小，而高度不会超过较短线的高度，面积只会更小。所以只有移动较短的线，才有可能找到更大的面积。

## 解法一：暴力枚举

### 思路

枚举所有可能的两条线组合，计算每种组合的面积，取最大值。

### 算法步骤

1. 双重循环遍历所有 `(i, j)` 对，其中 `i < j`
2. 对每对计算面积 `min(height[i], height[j]) * (j - i)`
3. 记录最大面积

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 解法二：双指针（推荐）

### 思路

左右双指针从两端向中间收缩。每次移动较短的那条线——因为面积受限于较短边，移动较长边不可能获得更大面积，只有移动较短边才可能遇到更高的线从而增加面积。

### 算法步骤

1. 初始化左指针 `left = 0`，右指针 `right = n - 1`，最大面积 `max_area = 0`
2. 计算当前面积 `min(height[left], height[right]) * (right - left)`，更新 `max_area`
3. 若 `height[left] < height[right]`，则 `left++`；否则 `right--`
4. 重复步骤 2-3，直到 `left >= right`
5. 返回 `max_area`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
