# 114.二叉树展开为链表 解题思路

## 问题分析

将二叉树按先序遍历顺序展开为链表，所有节点的 `left` 为 `null`，`right` 指向下一个节点。

**关键洞察：** 先序遍历顺序是"根→左→右"，所以展开后：
- 当前节点的 `right` 指向左子树的先序第一个节点
- 左子树的最右节点的 `right` 指向原右子树

## 解法一：递归（后序遍历变体）

### 思路

递归地将左右子树展开为链表，然后将左链表接到根的 `right`，再将原右链表接到左链表的末尾。

### 算法步骤

1. 递归展开左子树和右子树
2. 保存原右子树 `right = root.right`
3. 将左子树移到 `root.right`，`root.left = null`
4. 找到新 `right` 链表的末尾，接上原右子树

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈深度

## 解法二：迭代（栈模拟先序遍历）

### 思路

用栈做先序遍历，记录遍历顺序，然后依次连接。

### 算法步骤

1. 用栈做先序遍历，得到节点列表
2. 遍历列表，将每个节点的 `left` 置空，`right` 指向下一个节点

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈和列表存储

## 解法三：原地算法 O(1) 空间（推荐）

### 思路

对于每个节点，如果有左子树：
1. 找到左子树的最右节点（前驱节点）
2. 将原右子树接到前驱节点的 `right`
3. 将左子树移到 `right`，`left` 置空
4. 继续处理下一个节点

### 算法步骤

1. `curr = root`
2. 当 `curr` 不为空时：
   - 若 `curr.left` 存在：
     - 找到左子树的最右节点 `predecessor`
     - `predecessor.right = curr.right`
     - `curr.right = curr.left`
     - `curr.left = null`
   - `curr = curr.right`

### 复杂度分析

- 时间复杂度：O(n)，虽然有两层循环，但每条边最多访问两次
- 空间复杂度：O(1)，只用了常数个指针

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 | O(n) | O(h) | 直观易懂 |
| 迭代（栈） | O(n) | O(n) | 模拟先序遍历 |
| 原地算法 | O(n) | O(1) | 最优解，满足进阶要求 |
