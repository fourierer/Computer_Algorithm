# 1143.最长公共子序列 解题思路

## 问题分析

关键洞察：
- 子序列不要求连续，只要求相对顺序一致
- 典型二维 DP：`dp[i][j]` 表示 `text1[:i]` 和 `text2[:j]` 的最长公共子序列长度

## 解法一：二维 DP（推荐）

### 思路

定义 `dp[i][j]` 为 `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的最长公共子序列长度。

DP 表尺寸为 `(m+1) × (n+1)`，其中 `i` 取 `0..m`，`j` 取 `0..n`。`i=0` 和 `j=0` 对应空串边界，+1 是为了容纳空串初始值，否则递推缺少初始值。

边界条件：
- `dp[i][0] = 0`：`text1[:i]` 与空串的公共子序列长度为 0
- `dp[0][j] = 0`：空串与 `text2[:j]` 的公共子序列长度为 0

状态转移：
- 若 `text1[i-1] == text2[j-1]`：末尾字符相同，可以加入子序列
  - `dp[i][j] = dp[i-1][j-1] + 1`
- 若 `text1[i-1] != text2[j-1]`：末尾字符不同，取两种可能的最大值
  - `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
  - `dp[i-1][j]`：跳过 `text1[i-1]`，即 `text1[:i-1]` 与 `text2[:j]` 的结果
  - `dp[i][j-1]`：跳过 `text2[j-1]`，即 `text1[:i]` 与 `text2[:j-1]` 的结果

### 算法步骤

1. 初始化 `(m+1) × (n+1)` 的 DP 表，全部填 0（边界条件自然满足）
2. 双层循环遍历 `i=1..m, j=1..n`
3. 字符相同则取左上角 +1，否则取上方和左方的较大值
4. 返回 `dp[m][n]`

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二维 DP | O(m×n) | O(m×n) | 直观易懂，经典解法 |
| 一维 DP 滚动 | O(m×n) | O(n) | 空间优化，仅保留上一行 |
