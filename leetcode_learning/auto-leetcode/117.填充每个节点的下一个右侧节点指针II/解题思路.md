# 117.填充每个节点的下一个右侧节点指针 II 解题思路

## 问题分析

需要将每一层的节点通过 `next` 指针串成链表。与 116 题（完美二叉树）不同，本题的二叉树不一定是满的，因此不能简单地用 `node.left.next = node.right` 来连接。

**关键洞察：** 利用已经建好的当前层 `next` 链表来遍历当前层，同时为下一层建立 `next` 链表。用一个哑节点（dummy）作为下一层链表的头，遍历当前层时依次将子节点串到哑节点后面。

## 解法一：BFS 层序遍历

### 思路

用队列做标准层序遍历，每层内将相邻节点的 `next` 指针连接。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列存储

## 解法二：利用已建立的 next 指针（推荐）

### 思路

逐层处理：
1. 用 `curr` 遍历当前层（通过 `next` 指针）
2. 用 `dummy` 作为下一层的哑头节点，`prev` 指向下一层链表的尾部
3. 遍历当前层每个节点时，将其非空子节点依次接到 `prev` 后面
4. 当前层遍历完后，`curr = dummy.next` 进入下一层

### 算法步骤

1. `curr = root`
2. 当 `curr` 不为空时：
   - 创建 `dummy = Node(0)`，`prev = dummy`
   - 遍历当前层：`while curr`
     - 若 `curr.left` 存在，`prev.next = curr.left`，`prev = prev.next`
     - 若 `curr.right` 存在，`prev.next = curr.right`，`prev = prev.next`
     - `curr = curr.next`
   - `curr = dummy.next`（进入下一层）

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(1)，只用了常数个指针

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| BFS 层序遍历 | O(n) | O(n) | 直观易懂 |
| next 指针遍历 | O(n) | O(1) | 最优解，满足进阶要求 |
