# 12.整数转罗马数字 解题思路

## 问题分析

关键洞察：
- 罗马数字由固定符号组合表示，将所有可能的组合（包括特殊减法组合）从大到小排列
- 对每个符号值，尽可能多地使用（贪心），直到剩余数小于该值，再尝试下一个更小的符号值
- 本质就是"将数字用一组面值从大到小兑换"

## 解法：贪心查表（推荐）

### 思路

将所有的罗马数字符号值（含特殊组合）按从大到小排列，形成一个值-符号对列表。从大到小逐一尝试：每次尽可能多地使用当前符号，剩余数减去对应值，直到剩余为 0。

### 算法步骤

1. 建立值-符号对列表，从大到小排列：
   ```
   [(1000, 'M'), (900, 'CM'), (500, 'D'), (400, 'CD'),
    (100, 'C'), (90, 'XC'), (50, 'L'), (40, 'XL'),
    (10, 'X'), (9, 'IX'), (5, 'V'), (4, 'IV'), (1, 'I')]
   ```
2. 对每个值-符号对：
   - 用 `divmod(num, value)` 得到商和余数
   - 商为该符号重复的次数，追加到结果
   - `num = 余数`
3. 返回结果字符串

### 复杂度分析

- 时间复杂度：O(1)（符号对数量固定为 13，数值范围有限）
- 空间复杂度：O(1)
