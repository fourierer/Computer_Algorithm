# 120.三角形最小路径和 解题思路

## 问题分析

关键洞察：
- 三角形每行的第 j 个元素，只能从上一行的第 j-1 或第 j 个元素到达
- 定义 `f[i][j]` 为从顶点到第 i 行第 j 列的最小路径和
- 状态转移：`f[i][j] = min(f[i-1][j-1], f[i-1][j]) + triangle[i][j]`

## 边界条件

需要单独处理每一行的两端：
- `f[i][0]`：只能从上一行最左端到达，`f[i][0] = f[i-1][0] + triangle[i][0]`
- `f[i][i]`：只能从上一行最右端到达，`f[i][i] = f[i-1][i-1] + triangle[i][i]`

## 解法一：二维 DP（推荐）

### 思路

自顶向下逐行计算，最后取最后一行的最小值。

### 算法步骤

1. `f[0][0] = triangle[0][0]`
2. 从第 1 行开始逐行计算：
   - 左边界：`f[i][0] = f[i-1][0] + triangle[i][0]`
   - 中间位置：`f[i][j] = min(f[i-1][j-1], f[i-1][j]) + triangle[i][j]`
   - 右边界：`f[i][i] = f[i-1][i-1] + triangle[i][i]`
3. 返回 `min(f[n-1])`

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(n²)

## 解法二：空间优化（一维数组）

### 思路

`f[i][j]` 只依赖上一行 `f[i-1][j-1]` 和 `f[i-1][j]`，可以用一维数组从右往左更新，空间优化到 O(n)。

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二维 DP | O(n²) | O(n²) | 直观易懂 |
| 一维 DP | O(n²) | O(n) | 空间最优 |
