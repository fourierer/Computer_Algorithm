# 1209.删除字符串中的所有相邻重复项II 解题思路

## 问题分析

暴力模拟（反复扫描删除）会 O(n * k) 超时。

关键 trick：**栈存储 `(字符, 连续计数)`**，一次遍历完成：
- 若栈顶字符与当前相同，计数 +1
- 计数达到 `k` 则弹出（相当于删除了这 k 个）
- 否则压入新字符，计数为 1

## 解法一：栈 + 计数（推荐）

### 算法步骤

1. 栈 `stack` 存储 `(char, count)` 对
2. 遍历 `s`：
   - 若栈非空且栈顶字符 == 当前字符：栈顶 count +1
   - 否则压入 `(char, 1)`
   - 若栈顶 count == k：弹栈
3. 用栈中剩余字符拼成结果

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)
