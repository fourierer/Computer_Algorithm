# 1209.删除字符串中的所有相邻重复项II

- 难度：中等
- 题目链接：https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string-ii/

## 题目描述

给你一个字符串 `s`，一个整数 `k`，请重复执行如下操作直到无法继续：

- 选择 `s` 中**恰好** `k` 个**连续**且**相同**的字符，并删除它们。

返回最终得到的字符串。

## 示例

**示例 1：**
```
输入：s = "abcd", k = 2
输出："abcd"
解释：没有恰好 2 个相邻相同的字符可删。
```

**示例 2：**
```
输入：s = "deeedbbcccbdaa", k = 3
输出："aa"
解释：先删 "eee" → "ddbbcccbdaa"，再删 "ccc" → "ddbbbdaa"，
      再删 "bbb" → "dddaa"，再删 "ddd" → "aa"。
```

**示例 3：**
```
输入：s = "pbbcggttciiippooaais", k = 2
输出："ps"
```

## 提示

- `1 <= s.length <= 10^5`
- `2 <= k <= 10^4`
- `s` 仅由小写英文字母组成
