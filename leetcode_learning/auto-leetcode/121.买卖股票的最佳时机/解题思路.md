# 121.买卖股票的最佳时机 解题思路

## 问题分析

关键洞察：
- 买入必须在卖出之前，且只允许一次交易
- 最大利润 = 某天的价格 - 该天之前的历史最低价格
- 遍历时只需维护两个值：历史最低价、最大利润

## 解法一：暴力枚举（超时）

### 思路

枚举所有买入卖出组合，计算最大利润。

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 解法二：一次遍历，维护最小值（推荐）

### 思路

遍历价格数组，维护到当前位置为止的最低价格 `min_price`。对每一天，计算 `prices[i] - min_price` 作为当天卖出的最大利润，更新全局最大利润。

为什么正确？因为 `min_price` 始终是第 `i` 天之前的最低价，所以 `prices[i] - min_price` 就是第 `i` 天卖出能获得的最大利润。

### 算法步骤

1. `min_price = prices[0]`，`max_profit = 0`
2. 从第 1 天开始遍历：
   - `max_profit = max(max_profit, prices[i] - min_price)`
   - `min_price = min(min_price, prices[i])`
3. 返回 `max_profit`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力枚举 | O(n²) | O(1) | 会超时 |
| 维护最小值 | O(n) | O(1) | 最优解，一次遍历搞定 |
