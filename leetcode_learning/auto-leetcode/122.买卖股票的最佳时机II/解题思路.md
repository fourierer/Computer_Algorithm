# 122.买卖股票的最佳时机II 解题思路

## 问题分析

关键洞察：
- 与第 121 题的区别：可以多次交易（但同一时刻最多持有一股）
- 所有上涨段都可以贪心地吃满：只要今天比昨天高，就昨天买入今天卖出
- 数学上等价于：最大利润 = 所有 `prices[i] - prices[i-1] > 0` 的差值之和

为什么贪心正确？因为可以无限次交易，每次上涨都参与相当于一直在持有。例如 `[1,2,3,4]`，买1卖4利润=3，等价于买1卖2 + 买2卖3 + 买3卖4 = 1+1+1=3。

## 解法一：贪心（推荐）

### 思路

遍历价格数组，只要今天比昨天涨了，就把涨幅累加到利润中。

### 算法步骤

1. `profit = 0`
2. 从第 1 天遍历到第 n-1 天：
   - 若 `prices[i] > prices[i-1]`，则 `profit += prices[i] - prices[i-1]`
3. 返回 `profit`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法二：动态规划

### 思路

定义两个状态：
- `dp[i][0]`：第 i 天**不持有**股票时的最大利润
- `dp[i][1]`：第 i 天**持有**股票时的最大利润

状态转移：
- `dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])`（昨天就没有，或昨天有今天卖掉）
- `dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])`（昨天就有，或昨天没有今天买入）

由于只依赖前一天，可以用两个变量滚动，空间优化到 O(1)。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（滚动变量）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 贪心 | O(n) | O(1) | 最简洁，直觉易懂 |
| 动态规划 | O(n) | O(1) | 通用框架，可推广到其他股票问题 |
