# 123.买卖股票的最佳时机III 解题思路

## 问题分析

关键洞察：
- 与第 122 题的区别：最多只能完成**两笔**交易
- "最多两笔交易"等价于四个状态机阶段的滚动：第一次买入 → 第一次卖出 → 第二次买入 → 第二次卖出
- 每个状态只需记录当前最优值，空间可以压缩到 O(1)

## 解法一：动态规划（4 个状态变量）

### 思路

定义 4 个状态变量：
- `buy1`：只进行过一次买入后的最大利润（即 -prices[i] 的最大值）
- `sell1`：完成第一笔交易后的最大利润
- `buy2`：完成第一笔交易并第二次买入后的最大利润
- `sell2`：完成第二笔交易后的最大利润

状态转移（按天遍历，用前一天的值更新）：
- `buy1 = max(buy1, -prices[i])`：第一次买入，取最便宜的买入价
- `sell1 = max(sell1, buy1 + prices[i])`：第一次卖出，等于第一次买入的成本 + 当前价格
- `buy2 = max(buy2, sell1 - prices[i])`：第二次买入，等于第一次卖出的利润 - 当前价格
- `sell2 = max(sell2, buy2 + prices[i])`：第二次卖出，等于第二次买入的成本 + 当前价格

初始化：`buy1 = buy2 = -prices[0]`，`sell1 = sell2 = 0`

### 算法步骤

1. 初始化 `buy1 = buy2 = -prices[0]`，`sell1 = sell2 = 0`
2. 从第 1 天遍历到第 n-1 天，依次更新四个状态：
   - `buy1 = max(buy1, -prices[i])`
   - `sell1 = max(sell1, buy1 + prices[i])`
   - `buy2 = max(buy2, sell1 - prices[i])`
   - `sell2 = max(sell2, buy2 + prices[i])`
3. 返回 `sell2`（最多两笔交易的最大利润）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 动态规划（4 变量滚动） | O(n) | O(1) | 最优解，通用框架可推广到 k 笔交易 |
