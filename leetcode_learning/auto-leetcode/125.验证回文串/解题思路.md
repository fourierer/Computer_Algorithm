# 125.验证回文串 解题思路

## 问题分析

判断字符串是否为回文串，需要先过滤非字母数字字符并统一转为小写，再判断正反是否相同。

## 解法一：过滤 + 反转比较

### 思路

遍历字符串，筛选出所有字母数字字符并转为小写存入列表，然后比较列表与其反转是否相同。

### 算法步骤

1. 遍历字符串，用 `isalnum()` 筛选字母数字字符
2. 将每个有效字符转为小写加入列表
3. 比较列表与反转列表是否相等

### 复杂度分析

- 时间复杂度：O(n)，遍历一次 + 反转比较
- 空间复杂度：O(n)，存储过滤后的字符列表

## 解法二：双指针（推荐）

### 思路

使用左右双指针从两端向中间遍历，跳过非字母数字字符，逐对比较字符（统一小写）。无需额外存储，原地比较。

### 算法步骤

1. 初始化左右指针 `left = 0`，`right = len(s) - 1`
2. 当 `left < right` 时：
   - 跳过 `left` 右侧的非字母数字字符
   - 跳过 `right` 左侧的非字母数字字符
   - 比较两指针指向字符的小写形式，不相等则返回 `False`
   - 相等则 `left += 1`，`right -= 1`
3. 遍历结束返回 `True`

### 复杂度分析

- 时间复杂度：O(n)，最多遍历一次字符串
- 空间复杂度：O(1)，只使用两个指针

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 过滤 + 反转比较 | O(n) | O(n) | 代码简洁直观 |
| 双指针 | O(n) | O(1) | 空间最优，无需额外存储 |
