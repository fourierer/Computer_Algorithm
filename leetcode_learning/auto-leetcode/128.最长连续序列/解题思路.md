# 128.最长连续序列 解题思路

## 问题分析

在未排序数组中找最长的连续整数序列。关键洞察：**如果一个数是某个连续序列的起点，那么 `num - 1` 不在集合中**。从每个起点向右扩展，即可得到完整序列长度。

## 解法一：哈希集合（推荐）

### 思路

将所有数放入集合实现 O(1) 查找。只从连续序列的**起点**开始向右扩展，避免重复计算。判断起点的方法：`num - 1` 不在集合中。

### 算法步骤

1. 将 `nums` 转为集合 `num_set`
2. 遍历集合中每个数 `num`：
   - 若 `num - 1` 不在集合中，说明 `num` 是某个连续序列的起点
   - 从起点开始，不断检查 `num + 1, num + 2, ...` 是否在集合中，计算序列长度
   - 更新最大长度
3. 返回最大长度

### 复杂度分析

- 时间复杂度：O(n)，每个数最多被访问两次（作为起点和作为序列中间元素）
- 空间复杂度：O(n)，集合存储所有元素

## 解法二：排序

### 思路

排序后遍历，统计连续序列长度。需处理重复元素。

### 复杂度分析

- 时间复杂度：O(n log n)，排序开销
- 空间复杂度：O(1) 或 O(n)，取决于排序实现

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希集合 | O(n) | O(n) | 满足题目 O(n) 要求 |
| 排序 | O(n log n) | O(1) | 代码简单但不满足 O(n) |
