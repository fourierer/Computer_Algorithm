# 13.罗马数字转整数 解题思路

## 问题分析

关键洞察：
- 罗马数字的规则：通常小数字在右，大数字在左，直接相加
- 唯一例外：小数字在大数字左边时表示相减（如 `IV = 4`、`IX = 9`）
- 因此，从左到右遍历时：如果当前字符对应的值**小于**右边字符对应的值，则减去当前值；否则加上当前值

## 解法：一次遍历

### 思路

遍历罗马数字字符串，将每个字符映射为对应数值。若当前值小于下一个值（形成减法组合），则减去当前值；否则加上当前值。

等价写法：最后一位直接加上，其余位若小于后一位则减，否则加。

### 算法步骤

1. 建立字符到数值的映射表
2. `result = 0`
3. 遍历 `i` 从 0 到 n-2：
   - 若 `value[s[i]] < value[s[i+1]]`：`result -= value[s[i]]`
   - 否则：`result += value[s[i]]`
4. 最后一位直接加上：`result += value[s[n-1]]`
5. 返回 `result`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
