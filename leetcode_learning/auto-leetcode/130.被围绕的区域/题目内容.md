# 130.被围绕的区域

- 难度：中等
- 题目链接：https://leetcode.cn/problems/surrounded-regions/

## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，**捕获** 所有被围绕的区域：

- **连接**：一个 `'O'` 与与其相邻（上下左右）的 `'O'` 直接相连
- **被围绕的区域**：不与边界上的 `'O'` 相连的 `'O'` 区域

将所有被围绕的区域中的 `'O'` 替换为 `'X'`。

## 示例

**示例 1：**
```
输入：board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
输出：[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
解释：被围绕的区域在边界上的 'O' 及其连通区域不会被填充，只有完全被 'X' 围绕的区域会被填充为 'X'。
```

**示例 2：**
```
输入：board = [["X"]]
输出：[["X"]]
```

## 提示

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`
