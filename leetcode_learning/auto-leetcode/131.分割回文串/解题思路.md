# 131.分割回文串 解题思路

## 问题分析

回溯枚举所有切分点，每次切出一个回文子串后继续递归剩余部分。

核心需要快速判断任意子串 `s[i..j]` 是否回文，有两种预处理方式：
- **DP 区间表**：`dp[i][j] = (s[i]==s[j]) and (j-i<2 or dp[i+1][j-1])`
- **中心扩展法**（同 [5.最长回文子串](../5.最长回文子串/) 的思路）：枚举每个中心，向两边扩展，**看到回文就标记** `is_pal[l][r]=True`

## 解法一：回溯 + 中心扩展标记回文表（推荐）

### 思路

借鉴 5.最长回文子串 的中心扩展法：遍历每个中心（奇/偶两种），从中心向两边扩展，只要 `s[l]==s[r]` 就标记 `is_pal[l][r]=True` 并继续扩展。一次遍历所有中心即可得到全部回文子串的位置，然后回溯切分。

### 算法步骤

1. 中心扩展标记回文表：
   - 对每个 `center`，分奇数长度（`l=r=center`）和偶数长度（`l=center, r=center+1`）
   - 向两边扩展，`s[l]==s[r]` 则 `is_pal[l][r]=True`，`l--, r++`
2. 回溯切分：从 `start` 尝试切到 `end`，若 `is_pal[start][end]` 为真则加入 path 递归
3. `start == n` 时收集一组方案

### 复杂度分析

- 时间复杂度：O(n^2)（中心扩展预处理）+ O(n * 2^n)（回溯）
- 空间复杂度：O(n^2)（回文表）

## 解法二：回溯 + DP 区间表

### 思路

用区间 DP 预处理回文表：`dp[i][j] = (s[i]==s[j]) and (j-i<2 or dp[i+1][j-1])`，逆序遍历 `i` 保证 `dp[i+1][j-1]` 已算出。

### 复杂度分析

- 时间复杂度：O(n^2)（DP 预处理）+ O(n * 2^n)（回溯）
- 空间复杂度：O(n^2)（DP 表）

## 解法对比

| 解法 | 预处理 | 思路来源 | 说明 |
|------|--------|---------|------|
| 中心扩展标记 | O(n^2) | 5.最长回文子串 | 直观，"看到回文就标记" |
| DP 区间表 | O(n^2) | 区间 DP | 递推式简洁 |
