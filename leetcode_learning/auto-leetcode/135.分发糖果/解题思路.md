# 135.分发糖果 解题思路

## 问题分析

关键洞察：
- 规则只有一条：相邻孩子中评分更高的获得更多糖果
- 这条规则可以拆解为两个方向的约束：
  - **左规则**：若 `ratings[i] > ratings[i-1]`，则 `candy[i] > candy[i-1]`
  - **右规则**：若 `ratings[i] > ratings[i+1]`，则 `candy[i] > candy[i+1]`
- 每个孩子最终的糖果数 = 同时满足左右规则的最小值，即 `max(left[i], right[i])`

## 解法：两次遍历（推荐）

### 思路

1. **从左到右**：若 `ratings[i] > ratings[i-1]`，则 `left[i] = left[i-1] + 1`；否则 `left[i] = 1`
2. **从右到左**：若 `ratings[i] > ratings[i+1]`，则 `right += 1`；否则 `right = 1`
3. 每个位置取 `max(left[i], right)` 累加

空间优化：右规则用变量 `right` 滚动计算，省去 `right` 数组。

### 算法步骤

1. 初始化 `left = [1] * n`
2. 从左到右遍历：若 `ratings[i] > ratings[i-1]`，`left[i] = left[i-1] + 1`
3. `right = 0`，`ret = 0`
4. 从右到左遍历：若 `ratings[i] > ratings[i+1]`，`right += 1`；否则 `right = 1`
5. `ret += max(left[i], right)`
6. 返回 `ret`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（left 数组），可优化为 O(1) 但代码较复杂
