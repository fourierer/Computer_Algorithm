# 136.只出现一次的数字 解题思路

## 问题分析

关键洞察：
- 除一个元素出现一次外，其余每个元素均出现两次
- 异或运算的性质在此完美适用：
  - `a ^ a = 0`：相同数异或结果为 0
  - `a ^ 0 = a`：任何数与 0 异或结果不变
  - 异或满足交换律和结合律：`a ^ b ^ a = a ^ a ^ b = 0 ^ b = b`
- 因此将所有数异或起来，出现两次的数互相抵消为 0，最终结果就是只出现一次的数

## 解法一：异或 + reduce（推荐）

### 思路

利用 `functools.reduce` 对数组连续异或，一行代码解决。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法二：异或 + 循环

### 思路

手动遍历数组，逐步异或，逻辑更直观。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 异或 + reduce | O(n) | O(1) | 最简洁，一行代码 |
| 异或 + 循环 | O(n) | O(1) | 逻辑更直观 |
