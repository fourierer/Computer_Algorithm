# 137.只出现一次的数字II 解题思路

## 问题分析

关键洞察：
- 136 题中其余元素出现两次，用异或可以抵消（`a ^ a = 0`）
- 本题其余元素出现三次，异或无法直接抵消（`a ^ a ^ a = a ≠ 0`）
- 换个角度：逐位统计，每个比特位上 1 出现的总次数，对 3 取余就是只出现一次的数在该位的值

## 解法一：逐位统计（推荐）

### 思路

对于 32 位整数的每一位：
1. 统计所有数字在该位上 1 出现的总次数 `total`
2. 如果 `total % 3 != 0`，说明只出现一次的数在该位为 1

为什么？因为出现三次的数，它们在每个比特位上贡献的 1 的个数都是 3 的倍数，取余后为 0；只有只出现一次的数会留下余数 1。

### Python 特殊处理：最高位（第 31 位）

Python 整数是任意精度的，没有固定 32 位。当只出现一次的数是负数时，第 31 位（符号位）为 1，`1 << 31` 在 Python 中只是正数 `2147483648`，不会自动变成负数。

解决方法：若第 31 位为 1，用 `ans -= (1 << 31)` 将其转为负数（即 `ans - 2^31`，等同于 32 位有符号整数中第 31 位为 1 的负数）。

### 算法步骤

1. `ans = 0`
2. 遍历 32 位 `i = 0..31`：
   - `total = sum((num >> i) & 1 for num in nums)`
   - 若 `total % 3 != 0`：
     - 若 `i == 31`（符号位），`ans -= (1 << 31)`
     - 否则，`ans |= (1 << i)`
3. 返回 `ans`

### 复杂度分析

- 时间复杂度：O(32n) = O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 逐位统计 | O(n) | O(1) | 直观易懂，Python 需注意符号位 |
| 有限状态机 | O(n) | O(1) | 更精巧但理解难度大 |
