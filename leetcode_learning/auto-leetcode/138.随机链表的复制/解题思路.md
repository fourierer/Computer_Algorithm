# 138.随机链表的复制 解题思路

## 问题分析

深拷贝含 `next` 和 `random` 指针的链表。难点在于 `random` 指针可能指向尚未创建的节点。关键洞察：**必须建立原节点到新节点的映射关系**，才能正确设置 `random` 指针。

## 解法一：哈希表映射（推荐）

### 思路

第一遍遍历创建所有新节点，用哈希表记录原节点到新节点的映射；第二遍遍历根据映射关系设置 `next` 和 `random` 指针。

### 算法步骤

1. 第一遍遍历：为每个原节点创建新节点，存入字典 `old_to_new`
2. 第二遍遍历：对每个原节点，设置新节点的 `next` 和 `random`：
   - `new_node.next = old_to_new[old_node.next]`
   - `new_node.random = old_to_new[old_node.random]`
3. 返回 `old_to_new[head]`

### 复杂度分析

- 时间复杂度：O(n)，遍历两次
- 空间复杂度：O(n)，哈希表存储映射

## 解法二：原地修改（交错链表）

### 思路

不使用额外哈希表，将新节点插入到原节点之后，形成交错链表。这样 `new_node.random = old_node.random.next`，利用原链表结构本身作为映射。

### 算法步骤

1. 在每个原节点后插入对应的新节点（A→A'→B→B'→...）
2. 设置新节点的 `random`：`new.random = old.random.next`
3. 拆分链表，恢复原链表并分离出新链表

### 复杂度分析

- 时间复杂度：O(n)，遍历三次
- 空间复杂度：O(1)，无需额外空间

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希表映射 | O(n) | O(n) | 逻辑清晰，面试首选 |
| 原地修改 | O(n) | O(1) | 空间最优，但会修改原链表 |
