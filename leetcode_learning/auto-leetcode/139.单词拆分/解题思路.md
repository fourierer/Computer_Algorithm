# 139.单词拆分 解题思路

## 问题分析

判断 `s` 能否由字典中的单词拼接而成。

DP 定义：`dp[i]` = `s[0..i-1]` 能否被拆分。
- `dp[0] = True`（空串可拆分）
- `dp[i] = True` 当存在 `j < i` 使得 `dp[j]` 且 `s[j..i-1]` 在字典中

优化 trick：只需遍历 `j` 在 `[i - max_len, i]` 范围内（最大单词长度内），避免全扫描。

## 解法一：动态规划（推荐）

### 算法步骤

1. 将 `wordDict` 转为 set 加速查找
2. `dp = [False] * (n + 1)`，`dp[0] = True`
3. 对每个 `i`，遍历 `j` 从 `max(0, i - max_len)` 到 `i`：
   - 若 `dp[j]` 且 `s[j:i]` 在 set 中，则 `dp[i] = True`，break
4. 返回 `dp[n]`

### 复杂度分析

- 时间复杂度：O(n * max_len * 单词查找)
- 空间复杂度：O(n)
