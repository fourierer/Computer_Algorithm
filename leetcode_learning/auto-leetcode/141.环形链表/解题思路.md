# 141.环形链表 解题思路

## 问题分析

判断链表是否有环。关键洞察：**快慢指针**——慢指针每次走一步，快指针每次走两步，若有环则两者必然相遇；若无环，快指针会先到达链表末尾。

为什么快慢指针一定相遇？设想环的长度为 `k`，当慢指针进入环时，快慢指针距离每次缩短1，必然在某一步相遇。

## 解法一：快慢指针（推荐）

### 思路

慢指针走一步，快指针走两步。若快指针到达末尾则无环，若快慢指针相遇则有环。

### 算法步骤

1. 初始化 `slow = head`，`fast = head`
2. 当 `fast` 和 `fast.next` 不为空时循环：
   - `slow = slow.next`
   - `fast = fast.next.next`
   - 若 `slow == fast`，返回 `True`
3. 循环结束返回 `False`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，只使用两个指针

## 解法二：哈希集合

### 思路

遍历链表，将每个节点加入集合。若某节点已在集合中，说明有环。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，集合存储所有节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 快慢指针 | O(n) | O(1) | 满足进阶要求，面试首选 |
| 哈希集合 | O(n) | O(n) | 直观易懂 |
