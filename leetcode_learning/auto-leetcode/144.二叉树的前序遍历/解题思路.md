# 144.二叉树的前序遍历 解题思路

## 问题分析

前序遍历顺序：**根 → 左 → 右**。需要同时掌握递归和迭代两种实现方式。

## 解法一：递归（DFS）

### 思路

定义递归函数 `traverse(node)`：
1. 若节点为空，返回
2. 访问当前节点（加入结果）
3. 递归遍历左子树
4. 递归遍历右子树

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树的高度（递归栈）

## 解法二：迭代（栈模拟）

### 思路

用显式栈模拟递归过程。前序遍历是"根左右"，所以入栈顺序是**先右后左**（栈是后进先出，后入的左子节点先出栈）。

### 算法步骤

1. 若 `root` 为空，返回空列表
2. 初始化栈 `stack = [root]`
3. 当栈不为空时：
   - 弹出栈顶节点，加入结果
   - 先将右子节点入栈（后访问）
   - 再将左子节点入栈（先访问）
4. 返回结果

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈最多存储一层节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 | O(n) | O(h) | 代码简洁，面试首选 |
| 迭代 | O(n) | O(n) | 用栈模拟，避免递归栈溢出 |
