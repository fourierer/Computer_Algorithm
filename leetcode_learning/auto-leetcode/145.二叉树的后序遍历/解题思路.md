# 145.二叉树的后序遍历 解题思路

## 问题分析

后序遍历顺序：**左 → 右 → 根**。需要同时掌握递归和迭代两种实现方式。

## 解法一：递归（DFS）

### 思路

定义递归函数 `traverse(node)`：
1. 若节点为空，返回
2. 递归遍历左子树
3. 递归遍历右子树
4. 访问当前节点（加入结果）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树的高度（递归栈）

## 解法二：迭代（栈模拟）

### 思路

**巧妙方法：** 后序遍历是"左右根"，反过来就是"根右左"。我们可以用类似前序遍历的方式（根左右 → 改为根右左），最后将结果反转即可。

### 算法步骤

1. 若 `root` 为空，返回空列表
2. 初始化栈 `stack = [root]`
3. 当栈不为空时：
   - 弹出栈顶节点，加入结果
   - 先将左子节点入栈（后访问）
   - 再将右子节点入栈（先访问）
4. 将结果反转后返回

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 | O(n) | O(h) | 代码简洁，面试首选 |
| 迭代 | O(n) | O(n) | 前序变体 + 反转，巧妙 |
