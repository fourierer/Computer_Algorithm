# 145.二叉树的后序遍历

- 难度：简单
- 题目链接：https://leetcode.cn/problems/binary-tree-postorder-traversal/

## 题目描述

给你二叉树的根节点 `root`，返回它节点值的 **后序** 遍历。

后序遍历顺序：左子树 → 右子树 → 根节点

## 示例

**示例 1：**
```
输入：root = [1,null,2,3]
输出：[3,2,1]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [1]
输出：[1]
```

## 提示

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`
