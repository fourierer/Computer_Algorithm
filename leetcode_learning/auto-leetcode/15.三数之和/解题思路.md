# 15.三数之和 解题思路

## 问题分析

找出数组中和为 0 的所有不重复三元组。核心难点在于**去重**：暴力枚举 O(n³) 且容易产生重复结果。排序后使用双指针可将复杂度降至 O(n²)，同时利用有序性方便去重。

## 解法一：排序 + 双指针（推荐）

### 思路

先排序数组，固定第一个数 `a`，然后在剩余区间用双指针找 `b + c = -a`。排序后相同的数相邻，通过跳过重复值实现去重。

### 算法步骤

1. 对数组排序
2. 枚举 `a`（外层循环 `first`）：
   - 跳过与上次相同的值，避免重复三元组
   - `target = -nums[first]`
   - `third` 指针初始指向数组最右端
3. 枚举 `b`（内层循环 `second`，从 `first + 1` 开始）：
   - 跳过与上次相同的值，避免重复
   - 若 `nums[second] + nums[third] > target`，`third` 左移
   - 若 `second == third`，说明找不到满足条件的 `c`，跳出内层循环
   - 若 `nums[second] + nums[third] == target`，记录结果

### 复杂度分析

- 时间复杂度：O(n²)，排序 O(n log n)，双指针遍历 O(n²)
- 空间复杂度：O(log n)，排序所需额外空间

## 解法二：哈希表

### 思路

固定 `a` 和 `b`，用哈希表查找 `c = -(a + b)`。需要额外的去重逻辑，实现较复杂。

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(n)，哈希表存储

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 排序 + 双指针 | O(n²) | O(log n) | 去重简单，面试首选 |
| 哈希表 | O(n²) | O(n) | 去重复杂，不推荐 |
