# 155.最小栈 解题思路

## 问题分析

要求所有操作都是 O(1) 时间复杂度，包括 `getMin`。关键洞察：**用辅助栈同步记录每个位置对应的最小值**。主栈和辅助栈同 push 同 pop，辅助栈栈顶始终是当前主栈的最小值。

## 解法一：辅助栈（推荐）

### 思路

维护两个栈：`stack` 存数据，`min_stack` 存每个元素入栈时的当前最小值。每次 `push` 时，将 `min(当前最小值, val)` 同时压入 `min_stack`；每次 `pop` 时两个栈同步弹出。

### 算法步骤

1. `push(val)`：将 `val` 压入主栈，将 `min(val, min_stack栈顶)` 压入辅助栈
2. `pop()`：两个栈同步弹出栈顶
3. `top()`：返回主栈栈顶
4. `getMin()`：返回辅助栈栈顶

### 复杂度分析

- 时间复杂度：所有操作均为 O(1)
- 空间复杂度：O(n)，辅助栈最多与主栈等大

## 解法二：单栈存储差值

### 思路

只维护一个栈，存储元素与当前最小值的差值。通过差值推导最小值和原值，节省辅助栈空间。

### 复杂度分析

- 时间复杂度：所有操作均为 O(1)
- 空间复杂度：O(n)，只用一个栈

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 辅助栈 | O(1) 均摊 | O(n) | 逻辑清晰，面试首选 |
| 单栈差值 | O(1) 均摊 | O(n) | 空间节省一倍，但有溢出风险 |
