# 167.两数之和II-输入有序数组 解题思路

## 问题分析

在有序数组中找到两个数使其和为 `target`。数组已按非递减顺序排列，这一性质是解题关键。题目要求使用常量级额外空间。

## 解法一：双指针（推荐）

### 思路

利用数组有序性，设置左右指针分别指向首尾。若两数之和小于目标，左指针右移（增大）；若大于目标，右指针左移（减小）。恰好等于则返回。

### 算法步骤

1. 初始化 `low = 0`，`high = len(numbers) - 1`
2. 当 `low < high` 时：
   - 计算 `total = numbers[low] + numbers[high]`
   - 若 `total == target`：返回 `[low + 1, high + 1]`（题目要求下标从 1 开始）
   - 若 `total < target`：`low += 1`（和太小，需要增大）
   - 若 `total > target`：`high -= 1`（和太大，需要减小）
3. 未找到返回 `[-1, -1]`

### 复杂度分析

- 时间复杂度：O(n)，最多遍历 n 次
- 空间复杂度：O(1)，只使用两个指针

## 解法二：二分查找

### 思路

对每个数 `numbers[i]`，在 `i+1` 到末尾范围内二分查找 `target - numbers[i]`。

### 算法步骤

1. 遍历 `i` 从 0 到 n-1
2. 对每个 `i`，在 `[i+1, n-1]` 范围内二分查找 `target - numbers[i]`
3. 找到则返回 `[i+1, j+1]`

### 复杂度分析

- 时间复杂度：O(n log n)，每个元素做一次二分查找
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双指针 | O(n) | O(1) | 最优解，利用有序性 |
| 二分查找 | O(n log n) | O(1) | 思路直观但效率略低 |
