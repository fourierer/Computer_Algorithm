# 179.最大数 解题思路

## 问题分析

核心 trick：**自定义排序比较器**。

对于两个数 `a` 和 `b`，比较 `a+b` 和 `b+a`（字符串拼接）哪个更大：
- 若 `a+b > b+a`，则 `a` 应排在 `b` 前面
- 例：`3` 和 `30` → `"330" > "303"`，所以 `3` 排在 `30` 前

## 解法一：自定义排序（推荐）

### 算法步骤

1. 将所有数字转为字符串
2. 用 `functools.cmp_to_key` 定义比较器：`a+b > b+a` 返回 -1（a 在前）
3. 排序后拼接
4. 若结果首字符为 '0'（全零），返回 "0"

### 复杂度分析

- 时间复杂度：O(n log n * L)，L 为字符串平均长度
- 空间复杂度：O(n * L)
