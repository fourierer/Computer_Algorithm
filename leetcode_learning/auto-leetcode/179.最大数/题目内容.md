# 179.最大数

- 难度：中等
- 题目链接：https://leetcode.cn/problems/largest-number/

## 题目描述

给定一组非负整数 `nums`，重新排列它们使它们组成一个最大的整数，并返回字符串。

因为结果可能非常大，所以你需要返回一个字符串而不是整数。

## 示例

**示例 1：**
```
输入：nums = [10,2]
输出："210"
```

**示例 2：**
```
输入：nums = [3,30,34,5,9]
输出："9534330"
```

## 提示

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`
