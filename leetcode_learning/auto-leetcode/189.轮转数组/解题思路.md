# 189.轮转数组 解题思路

## 问题分析

关键洞察：
- 右轮转 k 位等价于：将数组分为 `nums[n-k:]` 和 `nums[:n-k]` 两段，交换顺序
- 例如 `[1,2,3,4,5,6,7]` k=3 → `[5,6,7,1,2,3,4]`
- 注意 k 可能大于 n，需要先取模 `k = k % n`

## 解法一：额外数组

### 思路

创建新数组，将 `nums[i]` 放到 `(i + k) % n` 的位置，再复制回去。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法二：三次翻转（推荐）

### 思路

翻转的妙用：
1. 翻转整个数组：`[1,2,3,4,5,6,7]` → `[7,6,5,4,3,2,1]`
2. 翻转前 k 个：`[5,6,7,4,3,2,1]`
3. 翻转后 n-k 个：`[5,6,7,1,2,3,4]`

每一步翻转都是 O(n)，总共 O(n)，且不需要额外空间。

### 算法步骤

1. `k = k % n`（处理 k > n 的情况）
2. 翻转整个数组 `nums.reverse()`
3. 翻转 `nums[0:k]`
4. 翻转 `nums[k:n]`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法三：环状替换

### 思路

每个元素直接移动到目标位置 `nums[(i+k) % n]`，但会被覆盖的元素需要先保存。按环依次替换，当一个环结束时回到起点。

环的个数 = `gcd(n, k)`。

### 算法步骤

1. `k = k % n`
2. 计算环的个数 `count = gcd(n, k)`
3. 对每个起始位置 `start`（0 到 count-1）：
   - `cur = start`，`prev = nums[start]`
   - 循环：将 `prev` 放到 `(cur + k) % n`，被替换的值存入 `prev`，`cur = (cur + k) % n`
   - 直到 `cur == start`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 额外数组 | O(n) | O(n) | 简单直观 |
| 三次翻转 | O(n) | O(1) | 最优雅，原地操作 |
| 环状替换 | O(n) | O(1) | 原地操作，但实现较复杂 |
