# 解题思路

## 题目分析

- **问题类型**：链表 / 双指针
- **关键约束**：$1 \leq n \leq sz$，保证 n 合法
- **核心难点**：单趟扫描定位倒数第 n 个结点，并处理头结点被删除的边界

## 思路一：快慢指针（推荐，一趟扫描）

### 核心思想

让快指针先走 $n$ 步，然后快慢指针同步前进。当快指针到达链表末尾时，慢指针恰好停在**待删除结点的前一个结点**。

### 关键：虚拟头结点

删除操作需要知道**前驱结点**，但头结点没有前驱。加一个 `dummy` 节点统一处理：

```
dummy → 1 → 2 → 3 → 4 → 5 → None
                ↑
            要删除的(倒数第2个)
        ↑
    slow 停在前驱位置
```

### 算法步骤

1. 创建 `dummy` 节点，`dummy.next = head`
2. `fast = slow = dummy`
3. 快指针先走 $n+1$ 步（走 $n+1$ 而非 $n$，这样 slow 最终停在待删除结点的**前驱**）
4. 快慢指针同步前进，直到 `fast` 为 `None`
5. `slow.next = slow.next.next`，删除目标结点
6. 返回 `dummy.next`

### 图示

以 `head = [1,2,3,4,5], n = 2` 为例：

```
初始：dummy → 1 → 2 → 3 → 4 → 5 → None
       ↑
     fast=slow

fast先走 n+1=3 步：
dummy → 1 → 2 → 3 → 4 → 5 → None
                ↑
              fast

同步前进：
dummy → 1 → 2 → 3 → 4 → 5 → None
        ↑           ↑
      slow        fast

同步前进：
dummy → 1 → 2 → 3 → 4 → 5 → None
            ↑           ↑
          slow         fast

同步前进：
dummy → 1 → 2 → 3 → 4 → 5 → None
                ↑               ↑
              slow    fast=None（退出）

slow.next = slow.next.next  →  跳过结点4
结果：1 → 2 → 3 → 5
```

### 为什么 fast 走 n+1 步？

- 如果 fast 走 n 步，同步前进后 slow 指向**待删除结点本身**
- 但删除需要前驱结点，走 n+1 步让 slow 刚好停在前驱位置

### 复杂度

- 时间：$O(L)$，$L$ 为链表长度，一趟扫描
- 空间：$O(1)$

## 思路二：两次遍历

### 核心思想

第一次遍历求链表长度 $L$，第二次遍历走到第 $L-n$ 个结点（即待删除的前驱），执行删除。

### 复杂度

- 时间：$O(L)$，两次遍历
- 空间：$O(1)$

## 两种方法对比

| 方法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| 快慢指针 | $O(L)$ | $O(1)$ | 一趟扫描，推荐 |
| 两次遍历 | $O(L)$ | $O(1)$ | 简单直接 |
