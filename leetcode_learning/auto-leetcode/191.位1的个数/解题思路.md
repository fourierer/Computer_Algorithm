# 191.位1的个数 解题思路

## 问题分析

关键洞察：
- 统计一个 32 位无符号整数中二进制位为 1 的个数
- 直接遍历 32 位逐位判断可行，但有更巧妙的位运算技巧

## 解法一：n & (n - 1) 逐位消除（推荐）

### 思路

`n & (n - 1)` 的效果是**去掉 n 的最低位的 1**：
- 例如 `n = 10110`，`n - 1 = 10101`，`n & (n - 1) = 10100`，最低位的 1 被消除
- 每消除一个 1 计数一次，直到 n 变为 0

优势：循环次数等于 1 的个数，而非位数 32。对于稀疏的数效率更高。

### 算法步骤

1. `ret = 0`
2. while `n != 0`：
   - `n = n & (n - 1)`，消除最低位的 1
   - `ret += 1`
3. 返回 `ret`

### 复杂度分析

- 时间复杂度：O(k)，k 为 1 的个数，最坏 O(32) = O(1)
- 空间复杂度：O(1)

## 解法二：逐位检查

### 思路

遍历 32 位，逐位与 `1 << i` 做与运算，若结果非 0 则该位为 1。

### 复杂度分析

- 时间复杂度：O(32) = O(1)，固定循环 32 次
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 说明 |
|------|-----------|------|
| n & (n-1) 逐位消除 | O(k) | 循环次数 = 1 的个数，更优 |
| 逐位检查 | O(32) | 固定循环 32 次 |
