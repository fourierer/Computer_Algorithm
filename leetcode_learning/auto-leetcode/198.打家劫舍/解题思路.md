# 198.打家劫舍 解题思路

## 问题分析

关键洞察：
- 不能偷相邻的房屋，即选了第 i 家就不能选第 i-1 家
- 对于第 i 家，只有两种选择：偷或不偷
  - 偷第 i 家：金额 = dp[i-2] + nums[i]（不能偷第 i-1 家）
  - 不偷第 i 家：金额 = dp[i-1]（与到第 i-1 家时相同）
- 取两者最大值：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

边界条件：
- `dp[0] = nums[0]`：只有一间房，只能偷它
- `dp[1] = max(nums[0], nums[1])`：两间房，偷金额更大的那间

## 解法一：一维 DP 数组

### 思路

用 `dp[i]` 表示偷到第 i 家时的最高金额，状态转移如上。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法二：滚动变量（推荐）

### 思路

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，用两个变量滚动即可，空间优化到 O(1)。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 一维 DP 数组 | O(n) | O(n) | 直观易懂 |
| 滚动变量 | O(n) | O(1) | 空间最优 |
