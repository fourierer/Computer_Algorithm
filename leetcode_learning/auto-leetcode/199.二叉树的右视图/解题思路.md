# 199.二叉树的右视图 解题思路

## 问题分析

关键洞察：
- "右视图"就是每层最右边的节点
- 本质是层序遍历（BFS），只需记录每层的最后一个节点
- 也可以用 DFS，记录每个深度首次从右侧访问到的节点

## 解法一：BFS 层序遍历（推荐）

### 思路

使用队列进行层序遍历，每层从左到右依次出队。当遍历到该层的最后一个节点时（`i == level_size - 1`），将其值加入结果。

### 算法步骤

1. 特判：若根节点为空，返回空列表
2. 初始化队列，将根节点入队
3. while 队列不为空：
   - 记录当前层的节点数 `level_size`
   - 依次出队 `level_size` 个节点：
     - 若是当前层最后一个节点（`i == level_size - 1`），将其值加入结果
     - 将左右子节点入队
4. 返回结果

### 复杂度分析

- 时间复杂度：O(n)，每个节点刚好访问一次
- 空间复杂度：O(n)，队列最多存储一层的节点

## 解法二：DFS 深度优先遍历

### 思路

按「根 → 右 → 左」的顺序遍历，每层第一次访问的节点就是最右边的节点。用深度判断是否是该层首次被访问。

### 算法步骤

1. `result` 列表记录每层右视图节点值
2. DFS 遍历，参数为 `(node, depth)`：
   - 若 `depth == len(result)`，说明是该层第一次访问（即最右节点），加入结果
   - 先递归右子树，再递归左子树（保证先访问右侧）
3. 返回结果

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树的高度（递归栈深度）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| BFS 层序遍历 | O(n) | O(n) | 直观，层序遍历天然适合 |
| DFS 深度优先 | O(n) | O(h) | 空间更优（最坏 O(n)） |
