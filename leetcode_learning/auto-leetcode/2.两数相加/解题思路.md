# 2.两数相加 解题思路

## 问题分析

两个链表按逆序存储数字，逐位相加并处理进位。关键洞察：**同时遍历两个链表，逐位相加，维护进位 carry**。链表本身就是逆序存储的，所以正好从个位开始逐位相加，无需反转。

## 解法一：逐位相加（推荐）

### 思路

同时遍历两个链表，对应位相加再加上进位，取个位作为当前位结果，十位作为下一位进位。注意处理链表长度不同以及最终进位可能多出一个节点的情况。

### 算法步骤

1. 初始化虚拟头节点 `dummy`，当前指针 `curr`，进位 `carry = 0`
2. 当 `l1` 或 `l2` 或 `carry` 不为空/0 时循环：
   - 取 `l1` 的值（已遍历完则为0），`l1` 前进
   - 取 `l2` 的值（已遍历完则为0），`l2` 前进
   - 计算 `total = val1 + val2 + carry`
   - `carry = total // 10`
   - 创建新节点 `total % 10`，连接到结果链表
3. 返回 `dummy.next`

### 复杂度分析

- 时间复杂度：O(max(m, n))，遍历较长的链表
- 空间复杂度：O(max(m, n))，结果链表长度
