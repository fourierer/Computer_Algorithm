# 202.快乐数 解题思路

## 问题分析

不断将数字替换为各位数字的平方和，判断最终能否到达1。关键洞察：**如果永远到不了1，一定会进入循环**（因为平方和序列的值有上界，有限状态必然出现重复）。

因此问题转化为：判断序列中是否出现1，或者出现循环。

## 解法一：哈希集合检测循环（推荐）

### 思路

用集合记录所有出现过的数，若某数重复出现说明进入了循环，返回 `False`；若到达1则返回 `True`。

### 算法步骤

1. 定义 `get_next(n)` 计算各位数字平方和
2. 初始化空集合 `seen`
3. 当 `n != 1` 且 `n` 不在 `seen` 中时循环：
   - 将 `n` 加入 `seen`
   - `n = get_next(n)`
4. 循环结束时返回 `n == 1`

### 复杂度分析

- 时间复杂度：O(log n)，每次迭代数字位数减少
- 空间复杂度：O(log n)，集合存储的历史数字数量

## 解法二：快慢指针检测循环

### 思路

不用额外空间，用快慢指针（Floyd判圈算法）：慢指针每次走一步，快指针每次走两步，若两者相遇且值为1则为快乐数，相遇时值非1则存在循环。

### 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)，无需额外存储

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希集合 | O(log n) | O(log n) | 直观易懂 |
| 快慢指针 | O(log n) | O(1) | 空间更优 |
