# 205.同构字符串 解题思路

## 问题分析

判断两个字符串是否同构：`s` 到 `t` 的字符映射必须是一一对应的。即：
- 相同字符映射到同一目标字符
- 不同字符不能映射到同一目标字符

因此需要**双向**检查：`s → t` 和 `t → s` 的映射都必须唯一。

## 解法一：双字典双向映射（推荐）

### 思路

用两个字典分别记录 `s→t` 和 `t→s` 的映射，遍历时检查映射是否一致。

### 算法步骤

1. 初始化 `s2t` 和 `t2s` 两个空字典
2. 遍历 `s` 和 `t` 的每对字符 `(ch_s, ch_t)`：
   - 若 `ch_s` 已在 `s2t` 中但映射不是 `ch_t`，返回 `False`
   - 若 `ch_t` 已在 `t2s` 中但映射不是 `ch_s`，返回 `False`
   - 否则建立映射
3. 遍历结束返回 `True`

### 复杂度分析

- 时间复杂度：O(n)，遍历一次
- 空间复杂度：O(∣Σ∣)，字符集大小

## 解法二：单字典值对映射

### 思路

用一个字典记录映射，检查时确保不同键不映射到同一个值。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(∣Σ∣)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双字典双向映射 | O(n) | O(∣Σ∣) | 逻辑清晰，面试首选 |
| 单字典值对映射 | O(n) | O(∣Σ∣) | 代码更短 |
