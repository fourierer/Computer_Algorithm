# 206.反转链表 解题思路

## 问题分析

反转整个单链表。关键洞察：遍历时逐个翻转指针方向，`cur.next` 从指向后继改为指向前驱。

## 解法一：迭代（推荐）

### 思路

用 `pre` 和 `cur` 双指针遍历链表，每次将 `cur.next` 指向 `pre`，然后两个指针同步后移。需要临时保存 `cur.next` 防止断链。

### 算法步骤

1. 初始化 `pre = None`，`cur = head`
2. 当 `cur` 不为空时循环：
   - 临时保存 `cur.next`
   - `cur.next = pre`（翻转指针）
   - `pre = cur`（pre 前进）
   - `cur = temp_next`（cur 前进）
3. 返回 `pre`（此时 `cur` 为 None，`pre` 指向新的头节点）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法二：递归

### 思路

递归到最后一个节点作为新头节点返回，回溯时将后继节点的 `next` 指向当前节点，当前节点的 `next` 置空。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归栈深度

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 迭代 | O(n) | O(1) | 面试首选，无栈溢出风险 |
| 递归 | O(n) | O(n) | 代码简洁，但栈空间为 O(n) |
