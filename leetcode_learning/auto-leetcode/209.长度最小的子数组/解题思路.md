# 209.长度最小的子数组 解题思路

## 问题分析

在正整数数组中找和 >= target 的最短连续子数组。由于数组元素均为正整数，子数组和随右端点右移单调递增，这为滑动窗口提供了天然条件。

## 解法一：滑动窗口（推荐）

### 思路

维护一个窗口 `[left, right]`，右端点不断扩展使窗口和增大，当窗口和 >= target 时收缩左端点以寻找更短子数组。

### 算法步骤

1. 初始化 `left = 0`，`sum = 0`，`ans = ∞`
2. 遍历 `right` 从 0 到 n-1：
   - 将 `nums[right]` 加入 `sum`
   - 当 `sum >= target` 时：
     - 更新 `ans = min(ans, right - left + 1)`
     - 从左侧收缩窗口：`sum -= nums[left]`，`left += 1`
3. 返回 `ans` 若已更新，否则返回 0

### 复杂度分析

- 时间复杂度：O(n)，每个元素最多被左指针和右指针各访问一次
- 空间复杂度：O(1)

## 解法二：前缀和 + 二分查找

### 思路

构造前缀和数组，对每个起点 `i`，在 `[i+1, n]` 范围内二分查找最小的 `j` 使得 `prefix[j] - prefix[i] >= target`。

### 复杂度分析

- 时间复杂度：O(n log n)，每个元素做一次二分查找
- 空间复杂度：O(n)，前缀和数组

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 滑动窗口 | O(n) | O(1) | 最优解，代码简洁 |
| 前缀和 + 二分 | O(n log n) | O(n) | 进阶思路，适合含负数的变体 |
