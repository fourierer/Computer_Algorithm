# 解题思路

## 题目分析

- **问题类型**：链表 / 归并
- **关键约束**：两个链表均升序，节点数 ≤ 50
- **核心观察**：两个链表已排序，每次只需比较两个头结点，取较小的接入结果链表

## 思路一：迭代（推荐）

### 核心思想

用虚拟头结点 + 尾指针，每次比较两个链表头部，取较小的接上去。

### 算法步骤

1. 创建 `dummy` 虚拟头结点，`tail = dummy`
2. 当 `list1` 和 `list2` 都非空：
   - 比较 `list1.val` 和 `list2.val`
   - 将较小的接到 `tail` 后面
   - 移动对应链表指针和 `tail`
3. 将剩余非空链表直接接到 `tail` 后面
4. 返回 `dummy.next`

### 图示

```
l1: 1 → 2 → 4
l2: 1 → 3 → 4

第1步: 1 vs 1 → 取 l1 的 1  →  dummy → 1
第2步: 2 vs 1 → 取 l2 的 1  →  dummy → 1 → 1
第3步: 2 vs 3 → 取 l1 的 2  →  dummy → 1 → 1 → 2
第4步: 4 vs 3 → 取 l2 的 3  →  dummy → 1 → 1 → 2 → 3
第5步: 4 vs 4 → 取 l1 的 4  →  dummy → 1 → 1 → 2 → 3 → 4
l2 剩余 [4] 直接接上 → 1 → 1 → 2 → 3 → 4 → 4
```

### 复杂度

- 时间：$O(m + n)$
- 空间：$O(1)$

## 思路二：递归

### 核心思想

两个链表头部较小的节点 + 剩余部分的合并结果。

### 递推关系

```
merge(l1, l2):
  if l1.val < l2.val:
    l1.next = merge(l1.next, l2)  →  return l1
  else:
    l2.next = merge(l1, l2.next)  →  return l2
```

### 图示

```
merge([1,2,4], [1,3,4])
  1 >= 1 → l2.next = merge([1,2,4], [3,4])
                       1 < 3  → l1.next = merge([2,4], [3,4])
                                            2 < 3  → l1.next = merge([4], [3,4])
                                                                 4 >= 3 → l2.next = merge([4], [4])
                                                                                  4 >= 4 → l2.next = merge([4], None)
                                                                                                   return [4]
                                                                                  return [4,4]
                                                                 return [3,4,4]
                                                     return [2,3,4,4]
                               return [1,2,3,4,4]
  return [1,1,2,3,4,4]
```

### 复杂度

- 时间：$O(m + n)$
- 空间：$O(m + n)$（递归栈）

## 两种方法对比

| 方法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| 迭代 | $O(m+n)$ | $O(1)$ | 推荐，无栈开销 |
| 递归 | $O(m+n)$ | $O(m+n)$ | 代码简洁，但栈空间大 |
