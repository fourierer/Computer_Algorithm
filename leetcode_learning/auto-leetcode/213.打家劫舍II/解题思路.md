# 213.打家劫舍II 解题思路

## 问题分析

与 [198.打家劫舍](../198.打家劫舍/) 的唯一区别：房屋**围成一圈**，首尾相邻。

关键洞察：
- 环形意味着**不能同时偷第一家和最后一家**（它们相邻）
- 因此最优解中，第一家和最后一家至少有一个不偷
- 把环形问题拆成两个线性问题，分别套用 198 题的解法：
  - **情况 A**：偷第一家 → 不偷最后一家 → 在 `nums[0..n-2]` 上做线性 DP
  - **情况 B**：不偷第一家 → 可偷最后一家 → 在 `nums[1..n-1]` 上做线性 DP
  - 答案 = `max(情况 A, 情况 B)`

边界条件：
- `n == 1`：只有一间房，两个区间都会退化，单独返回 `nums[0]`

## 解法一：一维 DP 数组

### 思路

复用 198 题的一维 DP：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。对两个子区间分别求解，取较大值。

### 算法步骤

1. 若 `n == 1`，直接返回 `nums[0]`
2. 定义辅助函数 `rob_range(l, r)` 在 `nums[l..r]` 上做 198 题的一维 DP
3. 返回 `max(rob_range(0, n-2), rob_range(1, n-1))`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法二：滚动变量（推荐）

### 思路

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，用两个变量滚动即可，空间优化到 O(1)。对两个子区间分别滚动求解。

### 算法步骤

1. 若 `n == 1`，直接返回 `nums[0]`
2. 定义辅助函数 `rob_range(l, r)`：
   - 若 `l == r`（单元素），返回 `nums[l]`
   - 否则用 `first = dp[i-2]`、`second = dp[i-1]` 滚动更新
3. 返回 `max(rob_range(0, n-2), rob_range(1, n-1))`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 一维 DP 数组 | O(n) | O(n) | 直观易懂 |
| 滚动变量 | O(n) | O(1) | 空间最优 |
