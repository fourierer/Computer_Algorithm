# 221.最大正方形 解题思路

## 问题分析

关键洞察：
- 定义 `dp[i][j]` 为以 `(i, j)` 为右下角的最大正方形边长
- 若 `matrix[i][j] == '1'`，则 `dp[i][j]` 取决于左方、上方、左上方三个位置的最小值 + 1
- 为什么取最小值？正方形要求四条边都是完整的，三个方向中最短的一条决定了正方形的最大边长

## 状态转移方程

若 `matrix[i][j] == '1'`：
```
dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```
若 `matrix[i][j] == '0'`：
```
dp[i][j] = 0
```

直觉理解：以 `(i,j)` 为右下角的正方形，其边长受限于左方、上方、左上方三个方向能延伸的最短边长。

## 边界条件

- 第一行和第一列：若 `matrix[i][j] == '1'`，则 `dp[i][j] = 1`（单独一个格子构成边长为 1 的正方形）
- 若 `matrix[i][j] == '0'`，则 `dp[i][j] = 0`

## 解法：二维 DP

### 算法步骤

1. 初始化 `dp` 数组，第一行和第一列根据 `matrix` 填入 0 或 1
2. 双层循环遍历中间位置，按状态转移方程计算
3. 记录过程中 `dp` 的最大值 `max_side`
4. 返回 `max_side * max_side`

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)
