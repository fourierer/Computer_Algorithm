# 226.翻转二叉树 解题思路

## 问题分析

翻转二叉树就是将每个节点的左右子树互换位置。这是一个经典的递归问题。

**关键洞察：** 翻转操作具有递归性质 — 翻转整棵树 = 翻转左子树 + 翻转右子树 + 交换左右子树。

## 解法一：DFS 递归（推荐）

### 思路

递归地翻转左右子树，然后交换当前节点的左右指针。

### 算法步骤

1. 若 `root` 为空，直接返回
2. 递归翻转左子树，得到 `left`
3. 递归翻转右子树，得到 `right`
4. 交换：`root.left = right`，`root.right = left`
5. 返回 `root`

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，h 为树的高度（递归栈深度）

## 解法二：BFS 迭代

### 思路

使用队列进行层序遍历，对每个节点交换其左右子树。

### 算法步骤

1. 若 `root` 为空，返回 `None`
2. 初始化队列 `queue = [root]`
3. 当队列不为空时：
   - 取出节点，交换其左右子树
   - 将非空子节点加入队列
4. 返回 `root`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，队列最多存储一层节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| DFS 递归 | O(n) | O(h) | 代码简洁，后序遍历变体 |
| BFS 迭代 | O(n) | O(n) | 层序遍历，逐层交换 |
