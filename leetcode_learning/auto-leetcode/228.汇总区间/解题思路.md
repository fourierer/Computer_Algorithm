# 228.汇总区间 解题思路

## 问题分析

将有序数组划分为连续的区间段。关键洞察：遍历数组时，只要当前元素与前一个元素不连续（差值不为1），就说明前一个区间结束，新区间开始。

## 解法一：一次遍历（推荐）

### 思路

维护每个区间的起点 `start`，遍历时检查是否与前一个数连续。若不连续，则输出上一个区间并更新起点。

### 算法步骤

1. 初始化结果列表 `result`，起点 `start = nums[0]`
2. 遍历数组（从索引1开始），对每个 `nums[i]`：
   - 若 `nums[i] != nums[i-1] + 1`，说明连续中断：
     - 将 `[start, nums[i-1]]` 格式化后加入结果
     - 更新 `start = nums[i]`
3. 遍历结束后，将最后一个区间加入结果
4. 返回结果

### 复杂度分析

- 时间复杂度：O(n)，遍历一次
- 空间复杂度：O(1)，不考虑结果列表的存储

## 解法二：双指针

### 思路

用左右指针标识区间边界，左指针为起点，右指针不断右移直到不连续。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 一次遍历 | O(n) | O(1) | 逻辑清晰，面试首选 |
| 双指针 | O(n) | O(1) | 指针语义更明确 |
