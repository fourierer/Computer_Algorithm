# 238.除自身以外数组的乘积 解题思路

## 问题分析

关键洞察：
- `answer[i]` = `nums[i]` 左侧所有元素的乘积 × 右侧所有元素的乘积
- 不能用除法，所以不能算总乘积再除以 `nums[i]`
- 可以分别计算出每个位置的**左乘积**和**右乘积**，再相乘

## 解法一：左右乘积数组

### 思路

用两个数组 `L` 和 `R`：
- `L[i]` = `nums[i]` 左侧所有元素的乘积
- `R[i]` = `nums[i]` 右侧所有元素的乘积
- `answer[i] = L[i] * R[i]`

计算方式：
- `L[0] = 1`，`L[i] = nums[i-1] * L[i-1]`（从左到右）
- `R[n-1] = 1`，`R[i] = nums[i+1] * R[i+1]`（从右到左）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（L 和 R 两个数组）

## 解法二：O(1) 额外空间（推荐）

### 思路

进阶要求 O(1) 额外空间（输出数组不计入）。

将解法一的空间优化：
1. 先用 `answer` 数组替代 `L` 数组（从左到右填充左乘积）
2. 用一个变量 `R` 替代 `R` 数组（从右到左遍历时，边计算右乘积边更新 `answer`）

### 算法步骤

1. **左乘积**：`answer[0] = 1`，`answer[i] = nums[i-1] * answer[i-1]`
2. **右乘积**：`R = 1`，从右到左遍历：
   - `answer[i] = answer[i] * R`（左乘积 × 右乘积）
   - `R *= nums[i]`（更新右侧累乘）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（输出数组不计入，仅用变量 R）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 左右乘积数组 | O(n) | O(n) | 思路清晰，用了 L 和 R 两个数组 |
| O(1) 额外空间 | O(n) | O(1) | 用 answer 数组替代 L，用变量 R 替代 R 数组 |
