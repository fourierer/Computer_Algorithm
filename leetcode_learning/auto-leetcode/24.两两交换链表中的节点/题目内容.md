# 24. 两两交换链表中的节点

| 项目 | 内容 |
|------|------|
| 题号 | 24 |
| 标题 | 两两交换链表中的节点 |
| 英文标题 | Swap Nodes in Pairs |
| 难度 | 中等 |
| 标签 | 递归, 链表 |

---

## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即只能进行节点交换）。

### 示例 1

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

图示：`1→2→3→4` 交换后变为 `2→1→4→3`

### 示例 2

```
输入：head = []
输出：[]
```

### 示例 3

```
输入：head = [1]
输出：[1]
```

### 提示

- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`
