# 2560.打家劫舍IV 解题思路

## 问题分析

与前几题不同：本题要求**至少偷 k 间**（而非最大金额），且要**最小化“单间最大金额”**。

关键洞察：
- 设能力值为 `x`：只有 `nums[i] <= x` 的房屋才允许偷
- 问题变为：在允许的房屋中，最多能选多少间**互不相邻**的房屋
- 若该数量 `>= k`，则能力值 `x` 可行，否则不可行
- **单调性**：`x` 越大，允许的房屋越多，可偷数量只增不减 → 可二分

### 贪心计数（核心）

对给定 `x`，求“允许房屋中最多互不相邻的房屋数”：
- 从左到右扫描，遇到 `nums[i] <= x` 就**贪心地偷**，并跳过 `i+1`（相邻不能偷）
- 此贪心在路径图上求最大独立集，是最优的

### 二分框架

- 下界 `lo = min(nums)`，上界 `hi = max(nums)`
- `check(x) >= k` → 缩小上界，否则抬升下界
- 收敛后 `lo` 即最小能力值

## 解法一：二分 + 贪心（推荐）

### 算法步骤

1. 令 `lo = min(nums)`，`hi = max(nums)`
2. `while lo < hi`：
   - `mid = (lo + hi) // 2`
   - 若 `check(mid) >= k`：`hi = mid`（mid 可行，尝试更小）
   - 否则：`lo = mid + 1`（mid 不可行，必须更大）
3. 返回 `lo`

### 复杂度分析

- 时间复杂度：O(n log V)，V = max(nums) - min(nums)，每次 check 为 O(n)
- 空间复杂度：O(1)

## 解法二：二分去重值集合

### 思路

搜索空间收敛到 `nums` 的**去重排序值**上，迭代次数为 O(log U)（U 为去重后元素数），在大值域下减少二分轮次。

### 复杂度分析

- 时间复杂度：O(n log n)（排序）+ O(n log U)（二分 + check）
- 空间复杂度：O(n)（去重排序数组）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二分 + 贪心 | O(n log V) | O(1) | 推荐，简单高效 |
| 二分去重值集合 | O(n log n) | O(n) | 值域极大时迭代更少 |
