# 2560.打家劫舍IV

- 难度：中等
- 题目链接：https://leetcode.cn/problems/house-robber-iv/

## 题目描述

街上有若干房屋排成一排，用一个非负整数数组 `nums` 表示，其中 `nums[i]` 表示第 `i` 号房屋存放的金额。

小偷想要偷窃**至少 `k` 间房屋**，且**不能偷窃相邻的两间房屋**。小偷的**能力值**定义为他所偷窃的房屋中**单间房屋的最大金额**。

返回小偷所需的**最小能力值**。

## 示例

**示例 1：**
```
输入：nums = [2,3,5,3], k = 2
输出：3
解释：能力值为 3 时，可偷第 0 号房屋（金额 = 2）和第 3 号房屋（金额 = 3），共 2 间且不相邻；
      能力值为 2 时只能偷第 0 号房屋（金额 = 2）这 1 间，不足 k=2。故最小能力值为 3。
```

**示例 2：**
```
输入：nums = [2,7,9,3,1], k = 2
输出：2
解释：能力值为 2 时，可偷第 0 号房屋（金额 = 2）和第 4 号房屋（金额 = 1），共 2 间且不相邻。
      能力值为 1 时只能偷第 4 号房屋这 1 间，不足 k=2。故最小能力值为 2。
```

## 提示

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= (nums.length + 1) / 2`
