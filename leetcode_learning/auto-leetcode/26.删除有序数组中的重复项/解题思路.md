# 26.删除有序数组中的重复项 解题思路

## 问题分析

关键洞察：数组已经**升序排列**，所以所有重复元素一定是**相邻**的。这给了我们很大的便利——只需比较相邻元素即可判断是否重复。

问题要求**原地**修改数组，且空间复杂度为 O(1)，这意味着不能用额外的数组或哈希表，必须在原数组上操作。

## 解法一：双指针（快慢指针）（推荐）

### 思路

使用两个指针：
- **慢指针 `slow`**：指向当前不重复元素应该放置的位置（即新数组的末尾）
- **快指针 `fast`**：遍历整个数组，寻找下一个不重复的元素

因为数组有序，只要 `nums[fast] != nums[slow]`，就说明 `nums[fast]` 是一个新的不重复元素，应该将其放到 `slow + 1` 的位置，然后 `slow` 前进一步。

### 算法步骤

1. 若数组为空，直接返回 0
2. 初始化慢指针 `slow = 0`
3. 快指针 `fast` 从 1 开始遍历数组
4. 当 `nums[fast] != nums[slow]` 时，说明发现新元素：
   - `slow` 前进一步（`slow += 1`）
   - 将 `nums[fast]` 复制到 `nums[slow]`
5. 遍历结束后，返回 `slow + 1`（即不重复元素的个数）

### 复杂度分析

- 时间复杂度：O(n)，只需一次遍历
- 空间复杂度：O(1)，只使用两个指针变量

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 双指针（快慢指针） | O(n) | O(1) | 最优解，利用有序性原地去重 |
| 暴力法（创建新数组） | O(n) | O(n) | 不满足原地修改要求 |
