# 27.移除元素 解题思路

## 问题分析

关键洞察：题目要求**原地**移除等于 `val` 的元素，且顺序可以改变。本质上是要把所有不等于 `val` 的元素"聚拢"到数组前端。

与第 26 题类似，这道题也适合用双指针解决，但有两种策略可选。

## 解法一：快慢指针（保持顺序）

### 思路

使用快慢指针：
- **慢指针 `slow`**：指向下一个不等于 `val` 的元素应该放置的位置
- **快指针 `fast`**：遍历整个数组

当 `nums[fast] != val` 时，将元素复制到 `slow` 的位置，然后 `slow` 前进。这样所有保留的元素会保持原有顺序。

### 算法步骤

1. 初始化 `slow = 0`
2. `fast` 从 0 开始遍历数组
3. 若 `nums[fast] != val`，则 `nums[slow] = nums[fast]`，`slow += 1`
4. 遍历结束，返回 `slow`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法二：左右指针（最优，覆盖交换）

### 思路

题目说明**元素的顺序可以改变**，那我们可以用更少的操作：当左边的元素等于 `val` 时，用右边的元素覆盖它，然后右指针左移。只有当当前元素不等于 `val` 时才左移左指针。

这种方式每个元素最多被访问一次（被检查或被覆盖），而快慢指针中每个元素都会被访问一次，但覆盖交换可以避免不必要的复制操作。

### 算法步骤

1. 初始化 `left = 0`，`right = len(nums) - 1`
2. 当 `left <= right` 时：
   - 若 `nums[left] == val`：用 `nums[right]` 覆盖 `nums[left]`，`right -= 1`（不移动 `left`，因为新覆盖的元素还需要检查）
   - 若 `nums[left] != val`：`left += 1`
3. 返回 `left`（即不等于 `val` 的元素个数）

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 是否保持顺序 | 赋值次数 |
|------|-----------|-----------|------------|---------|
| 快慢指针 | O(n) | O(1) | 是 | 较多 |
| 左右指针（覆盖交换） | O(n) | O(1) | 否 | 较少 |
