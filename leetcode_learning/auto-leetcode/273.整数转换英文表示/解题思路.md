# 273.整数转换英文表示 解题思路

## 问题分析

按 3 位一组递归处理，每组格式：`[百位] Hundred [十位] [个位] + 单位（Thousand / Million / Billion）`。

关键映射表：
- `ONES`：0-19 的英文
- `TENS`：20/30/.../90 的英文
- `THOUSANDS`：`['', 'Thousand', 'Million', 'Billion']`

## 解法一：分段递归（推荐）

### 算法步骤

1. `helper(num)` 处理 < 1000 的三位数：
   - `>= 100`：`ONES[num//100] + " Hundred" + helper(num % 100)`
   - `>= 20`：`TENS[num//10] + helper(num % 10)`
   - `>= 1`：`ONES[num]`
   - `== 0`：空
2. 主函数：每 3 位一组，从低位到高位调用 `helper`，拼接 `THOUSANDS[i]`
3. 拼接结果，去除多余空格

### 复杂度分析

- 时间复杂度：O(1)（num 最大 2^31，最多 4 组）
- 空间复杂度：O(1)
