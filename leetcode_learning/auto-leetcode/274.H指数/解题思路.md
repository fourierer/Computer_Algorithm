# 274.H指数 解题思路

## 问题分析

关键洞察：
- h 指数的定义：存在 h 篇论文，每篇引用次数 ≥ h，其余论文引用次数 ≤ h
- 排序后更易判断：从高到低排序，如果前 h 篇论文的引用次数都 ≥ h，则 h 指数至少为 h

## 解法一：排序（推荐）

### 思路

将引用次数从大到小排序。遍历排序后的数组，找到最大的 h 使得 `citations[h-1] >= h`。

即从位置 0 开始，只要 `citations[i] >= i + 1`，h 就可以增大。第一个不满足的位置 `i`，h 指数就是 `i`。

### 算法步骤

1. 将 `citations` 从大到小排序
2. `h = 0`
3. 遍历排序后的数组（下标 i）：
   - 若 `citations[i] >= i + 1`：`h = i + 1`
   - 否则：跳出循环
4. 返回 `h`

### 复杂度分析

- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(1)（原地排序）或 O(n)（取决于排序算法）

## 解法二：计数排序

### 思路

由于 h 指数不会超过论文总数 n，引用次数 > n 的论文等价于引用次数为 n。因此可以用长度 n+1 的计数数组，记录每个引用次数对应的论文篇数，再从高到低累计求 h 指数。

### 算法步骤

1. 创建 `counter[n+1]`，`counter[i]` 表示引用次数为 i 的论文篇数
2. 遍历 `citations`：若 `citations[i] >= n`，`counter[n] += 1`；否则 `counter[citations[i]] += 1`
3. 从 n 到 0 倒序累计：`total` 表示引用次数 ≥ i 的论文总数
   - 当 `total >= i` 时，h 指数为 `i`
4. 返回找到的 `i`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 排序 | O(n log n) | O(1) | 代码简洁，易于理解 |
| 计数排序 | O(n) | O(n) | 时间最优，适合 n 较大的场景 |
