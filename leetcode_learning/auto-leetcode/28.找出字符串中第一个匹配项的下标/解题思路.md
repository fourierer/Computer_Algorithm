# 28.找出字符串中第一个匹配项的下标 解题思路

## 问题分析

本质是字符串匹配问题：在主串 `haystack` 中查找模式串 `needle` 第一次出现的位置。

关键洞察：
- 暴力匹配简单直观，但每次失配后主串指针只回退一步，效率不高
- KMP 算法通过预处理模式串的"部分匹配信息"，使主串指针不回退，实现高效匹配

## 解法一：暴力匹配

### 思路

逐个尝试 `haystack` 中每个可能的起始位置，检查是否与 `needle` 完全匹配。

### 算法步骤

1. 遍历 `haystack` 中所有可能的起始位置 `i`（`0` 到 `len(haystack) - len(needle)`）
2. 对每个起始位置 `i`，逐字符比较 `haystack[i+j]` 与 `needle[j]`
3. 若完全匹配，返回 `i`；否则尝试下一个起始位置
4. 所有位置都尝试过后仍未匹配，返回 `-1`

### 复杂度分析

- 时间复杂度：O(m × n)，其中 m 是 `haystack` 长度，n 是 `needle` 长度
- 空间复杂度：O(1)

## 解法二：KMP 算法（推荐）

### 思路

KMP 算法的核心是**当匹配失败时，利用已匹配的信息避免主串指针回退**。

关键概念——**前缀表（next 数组 / lps 数组）**：
- `next[j]` 表示 `needle[0..j]` 这个子串中，**最长相等前后缀**的长度
- 当 `needle[j]` 与 `haystack[i]` 失配时，`next[j-1]` 告诉我们可以跳过多少字符，直接从 `needle[next[j-1]]` 继续匹配

**最长相等前后缀**举例：
- `"a"` → 0（没有真前缀和真后缀）
- `"aa"` → 1（前缀 `"a"` = 后缀 `"a"`）
- `"aab"` → 1（前缀 `"a"` = 后缀 `"b"` 不等，但前缀 `"a"` = 后缀 `"a"` 中最长为 1... 实际 `"aab"` 的真后缀是 `"ab"` 和 `"b"`，真前缀是 `"aa"` 和 `"a"`，只有 `"a"` 匹配 `"a"`，长度 1）

### 算法步骤

**构建 next 数组：**
1. 初始化 `next[0] = 0`，`j = 0`（`j` 表示当前最长相等前后缀长度）
2. `i` 从 1 遍历到 `len(needle)-1`：
   - 当 `j > 0` 且 `needle[i] != needle[j]` 时，回退 `j = next[j-1]`
   - 若 `needle[i] == needle[j]`，`j += 1`
   - `next[i] = j`

**匹配过程：**
1. `i` 遍历 `haystack`，`j` 指向 `needle` 中当前匹配位置
2. 当 `j > 0` 且 `haystack[i] != needle[j]` 时，回退 `j = next[j-1]`
3. 若 `haystack[i] == needle[j]`，`j += 1`
4. 若 `j == len(needle)`，完全匹配，返回 `i - j + 1`
5. 遍历结束未匹配，返回 `-1`

### 复杂度分析

- 时间复杂度：O(m + n)，构建 next 数组 O(n)，匹配 O(m)
- 空间复杂度：O(n)，next 数组

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力匹配 | O(m × n) | O(1) | 简单直观，适合入门 |
| KMP | O(m + n) | O(n) | 经典算法，主串指针不回退 |
