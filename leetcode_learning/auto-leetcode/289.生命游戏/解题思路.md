# 289.生命游戏 解题思路

## 问题分析

根据当前状态同时更新所有细胞到下一状态。核心难点在于**原地更新**：如果直接修改，后续细胞的邻居计算会受影响。需要一种方式在更新时同时保留当前和下一状态的信息。

## 解法一：额外数组

### 思路

复制一份原始面板，根据副本计算每个细胞的下一状态，写回原面板。简单直观但需要 O(mn) 额外空间。

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 解法二：原地标记（推荐）

### 思路

用额外的状态值同时编码当前和下一状态：
- `0` → 死→死
- `1` → 活→活
- `2` → 死→活（复活）
- `3` → 活→死（死亡）

统计活邻居时，值为 `1` 或 `3` 都算活细胞（当前状态为活）。更新完毕后，对所有值取模 2 得到最终状态。

### 算法步骤

1. 遍历每个细胞，统计其 8 个邻居中活细胞的数量（值为 1 或 3）
2. 根据规则设置新状态值：
   - 活细胞 + 邻居 < 2：标记为 3（活→死）
   - 活细胞 + 邻居 2 或 3：保持 1（活→活）
   - 活细胞 + 邻居 > 3：标记为 3（活→死）
   - 死细胞 + 邻居 == 3：标记为 2（死→活）
3. 第二次遍历，对所有值 `% 2` 得到最终状态

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(1)，原地更新

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 额外数组 | O(m×n) | O(m×n) | 简单直观 |
| 原地标记 | O(m×n) | O(1) | 最优解，面试首选 |
