# 290.单词规律 解题思路

## 问题分析

与 205.同构字符串 思路完全一致，只是从字符对字符变成了字符对单词。需要双向映射保证一一对应：`pattern` 中相同字母必须映射同一单词，不同字母不能映射同一单词。

## 解法一：双字典双向映射（推荐）

### 思路

用两个字典分别记录 `字符→单词` 和 `单词→字符` 的映射，遍历时检查映射是否一致。

### 算法步骤

1. 将 `s` 按空格分割为单词列表，若长度与 `pattern` 不同直接返回 `False`
2. 同时遍历 `pattern` 和单词列表：
   - 若字符已映射但映射单词不同，返回 `False`
   - 若单词已映射但映射字符不同，返回 `False`
   - 否则建立双向映射
3. 遍历结束返回 `True`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法二：单字典 + 值检查

### 思路

只用一个字典记录 `字符→单词`，检查新映射时确保值未被其他键映射。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 双字典双向映射 | O(n) | O(n) | 逻辑清晰，与205题一致 |
| 单字典 + 值检查 | O(n) | O(n) | 字典少一个，但值检查需遍历 |
