# 290.单词规律

- 难度：简单
- 题目链接：https://leetcode.cn/problems/word-pattern/

## 题目描述

给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。

这里的**遵循**指完全匹配，例如在 `pattern` 中的每个字母和字符串 `s` 中的每个非空单词之间存在着双向映射的对应规律。

## 示例

**示例 1：**
```
输入：pattern = "abba", s = "dog cat cat dog"
输出：true
```

**示例 2：**
```
输入：pattern = "abba", s = "dog cat cat fish"
输出：false
```

**示例 3：**
```
输入：pattern = "aaaa", s = "dog dog dog dog"
输出：true
```

**示例 4：**
```
输入：pattern = "abba", s = "dog dog dog dog"
输出：false
```

## 提示

- `1 <= pattern.length <= 300`
- `pattern` 只包含小写英文字母
- `s` 只包含小写英文字母和 `' '`
- `s` 中**不包含**前导或尾随空格
- `s` 中的所有单词由单个空格分隔
