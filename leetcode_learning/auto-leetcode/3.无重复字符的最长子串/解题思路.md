# 3.无重复字符的最长字串 解题思路

## 问题分析

求字符串中不含重复字符的最长连续子串的长度。核心在于维护一个"无重复字符的窗口"，当遇到重复字符时收缩左边界，否则扩展右边界。

## 解法：滑动窗口 + 集合

### 思路

用集合 `char_set` 维护当前窗口内的字符，左指针 `left` 和右指针 `right` 界定窗口范围。右指针每前进一步，若当前字符已在集合中，则不断从左边界移除字符并右移左指针，直到窗口内无重复；再将当前字符加入集合，更新最大长度。

### 算法步骤

1. 空字符串特判，返回 0
2. 初始化 `left = 0`，`max_length = 0`，空集合 `char_set`
3. 遍历右指针 `right` 从 0 到 n-1：
   - 当 `s[right]` 在 `char_set` 中时：
     - 移除 `s[left]`，`left += 1`（收缩左边界）
   - 将 `s[right]` 加入 `char_set`
   - 更新 `max_length = max(max_length, right - left + 1)`
4. 返回 `max_length`

### 复杂度分析

- 时间复杂度：O(n)，左右指针各最多遍历 n 次
- 空间复杂度：O(min(n, m))，m 为字符集大小（如 ASCII 为 128）
