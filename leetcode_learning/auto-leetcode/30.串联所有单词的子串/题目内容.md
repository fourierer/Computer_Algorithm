# 30.串联所有单词的子串

- 难度：困难
- 题目链接：https://leetcode.cn/problems/substring-with-concatenation-of-all-words/

## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`。`words` 中所有字符串**长度相同**。

`s` 中的**串联子串**是指一个包含 `words` 中所有字符串以任意顺序排列组合连接而成的子串。

例如，`words = ["ab","cd","ef"]`，那么 `"abcdef"`、`"abefcd"`、`"cdabef"`、`"cdefab"`、`"efabcd"`、`"efcdab"` 都是串联子串。`"acdbef"` 不是串联子串，因为 `cd` 和 `ef` 的顺序与 `words` 中不同。

返回所有串联子串在 `s` 中的起始索引。你可以按**任意顺序**返回答案。

## 示例

**示例 1：**
```
输入：s = "barfoothefoobarman", words = ["foo","bar"]
输出：[0,9]
解释：
从索引 0 和 9 开始的子串分别是 "barfoo" 和 "foobar"。
输出的顺序不重要，[9,0] 也是正确答案。
```

**示例 2：**
```
输入：s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
输出：[]
解释：因为 words 中有重复的 "word"，所以不存在符合条件的串联子串。
```

**示例 3：**
```
输入：s = "barfoofoobarthefoobarman", words = ["bar","foo","the"]
输出：[6,9,12]
解释：
从索引 6 开始的子串是 "foobarthe"，
从索引 9 开始的子串是 "barthefoo"，
从索引 12 开始的子串是 "thefoobar"。
```

## 提示

- `1 <= s.length <= 10^4`
- `1 <= words.length <= 5000`
- `1 <= words[i].length <= 30`
- `words` 中的字符串**长度相同**
- `s` 和 `words` 中的字符串仅由小写英文字母组成
