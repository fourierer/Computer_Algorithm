# 300.最长递增子序列 解题思路

## 问题分析

关键洞察：
- 子序列不要求连续，只要求相对顺序递增
- 定义 `dp[i]` 为以 `nums[i]` 结尾的最长递增子序列长度
- 对于每个 `nums[i]`，检查它前面所有比它小的 `nums[j]`，取最长的加 1

## 解法一：动态规划 O(n²)（推荐）

### 思路

状态定义：`dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长度

状态转移：
- `dp[i] = max(dp[j] + 1)`，对所有满足 `j < i` 且 `nums[j] < nums[i]` 的 j
- 含义：`nums[i]` 可以接在 `nums[j]` 后面形成更长的递增子序列
- 若前面没有比 `nums[i]` 更小的元素，则 `dp[i] = 1`（自身构成一个长度为 1 的子序列）

边界条件：`dp[i]` 初始化为 1（每个元素自身至少构成长度为 1 的子序列）

最终结果：`max(dp)`，即在所有以某个元素结尾的递增子序列中取最长的

### 算法步骤

1. 初始化 `dp` 数组全为 1
2. 双层循环：外层 `i` 从 1 到 n-1，内层 `j` 从 0 到 i-1
3. 若 `nums[j] < nums[i]`，更新 `dp[i] = max(dp[i], dp[j] + 1)`
4. 返回 `max(dp)`

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## 解法二：贪心 + 二分查找 O(n log n)

### 思路

维护一个数组 `tails`，`tails[i]` 表示长度为 `i+1` 的递增子序列的最小末尾元素。

遍历每个数：
- 若比 `tails` 末尾更大，直接追加（子序列长度 +1）
- 否则，用二分查找找到 `tails` 中第一个 ≥ 该数的位置并替换

为什么可以替换？更小的末尾元素更有可能让后续元素接上去形成更长的子序列。

### 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 动态规划 | O(n²) | O(n) | 直观易懂 |
| 贪心 + 二分 | O(n log n) | O(n) | 更优，适合大规模数据 |
