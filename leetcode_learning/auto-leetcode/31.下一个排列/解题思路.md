# 31.下一个排列 解题思路

## 问题分析

字典序下一个排列的几何直觉：
- 数组从右向左看，若一直是**升序**（即 `nums[i] >= nums[i+1]`），说明这部分已经是该前缀下的最大排列
- 找到第一个**降序**位置 `i`（`nums[i] < nums[i+1]`），说明 `nums[i]` 还能变大
- 变大的目标：在 `nums[i+1..n-1]`（降序段）中找到**大于 `nums[i]` 的最小值**，与 `nums[i]` 交换
- 交换后，`nums[i+1..n-1]` 仍为降序，将其**翻转为升序**即得到该前缀下的最小排列

关键洞察：
1. 从右找第一个下降点 `i`（若不存在，整体降序 → 直接全翻转为升序）
2. 在 `i` 右侧找大于 `nums[i]` 的最小值 `nums[j]`（降序段从右扫首个即可）
3. 交换 `nums[i]` 与 `nums[j]`
4. 翻转 `nums[i+1..n-1]`

## 解法一：标准算法（推荐）

### 算法步骤

1. 令 `i = n - 2`，向左扫描直到 `nums[i] < nums[i+1]`
2. 若 `i >= 0`：
   - 令 `j = n - 1`，向左扫描直到 `nums[j] > nums[i]`
   - 交换 `nums[i]` 与 `nums[j]`
3. 翻转 `nums[i+1..n-1]`（无论 `i` 是否找到，都翻转尾部；`i == -1` 时翻转整个数组）

### 复杂度分析

- 时间复杂度：O(n)（最多两趟扫描 + 一次翻转）
- 空间复杂度：O(1)（原地翻转）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 标准算法 | O(n) | O(1) | 满足题目常数空间要求，唯一最优 |
