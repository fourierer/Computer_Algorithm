# 322.零钱兑换 解题思路

## 问题分析

关键洞察：
- 完全背包问题：每种硬币可以无限使用，求凑成目标金额的最少硬币数
- 定义 `dp[i]` 为凑成金额 `i` 所需的最少硬币数
- 对每个金额 `i`，尝试每种硬币 `coin`：若使用该硬币，则 `dp[i] = dp[i - coin] + 1`

## 状态转移方程

- `dp[i] = min(dp[i], dp[i - coin] + 1)`，对所有满足 `coin <= i` 的硬币
- 含义：取不使用当前硬币和使用当前硬币中的较小值

## 边界条件与初始化

- `dp[0] = 0`：金额为 0 不需要硬币
- 其余 `dp[i]` 初始化为 `amount + 1`（一个不可能达到的大值，相当于"无穷大"）
  - 为什么用 `amount + 1`？最多需要 `amount` 个面值为 1 的硬币，所以 `amount + 1` 一定比任何合法答案都大
  - 这样 `min()` 比较时可以正确更新，且最终若 `dp[amount]` 未被更新就说明无法凑出

## 返回值

- 若 `dp[amount] > amount`：说明无法凑出，返回 `-1`
- 否则返回 `dp[amount]`

## 复杂度分析

- 时间复杂度：O(amount × len(coins))
- 空间复杂度：O(amount)
