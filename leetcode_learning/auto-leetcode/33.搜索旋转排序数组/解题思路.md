# 33.搜索旋转排序数组 解题思路

## 问题分析

关键洞察：
- 旋转后的数组仍然具有局部有序性：从中间切开，必定有一半是有序的
- 只需判断哪一半有序，就能确定 target 是否在该半边，从而缩小搜索范围

## 解法一：二分查找（推荐）

### 思路

每次取中点 `mid`，将与 `nums[left]` 比较来判断哪一半有序：
- 若 `nums[left] <= nums[mid]`，左半边 `[left, mid]` 有序
  - target 在左半边范围内 → 搜索左半边
  - 否则 → 搜索右半边
- 若 `nums[left] > nums[mid]`，右半边 `[mid, right]` 有序
  - target 在右半边范围内 → 搜索右半边
  - 否则 → 搜索左半边

### 算法步骤

1. 初始化 `left = 0, right = len(nums) - 1`
2. while `left <= right`：
   - 取 `mid = left + (right - left) // 2`
   - 若 `nums[mid] == target`，返回 `mid`
   - 判断哪一半有序：
     - 若左半边有序（`nums[left] <= nums[mid]`）：
       - `nums[left] <= target < nums[mid]` → `right = mid - 1`
       - 否则 → `left = mid + 1`
     - 若右半边有序（`nums[left] > nums[mid]`）：
       - `nums[mid] < target <= nums[right]` → `left = mid + 1`
       - 否则 → `right = mid - 1`
3. 未找到，返回 `-1`

### 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)
