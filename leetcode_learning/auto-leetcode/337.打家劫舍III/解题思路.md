# 337.打家劫舍III 解题思路

## 问题分析

房屋排成二叉树，约束变为：**不能同时偷父子节点**（父与子直接相连）。

关键洞察：
- 每个节点只有两种状态：偷 / 不偷
- 若偷当前节点，则其左右子节点都不能偷
- 若不偷当前节点，则其左右子节点可偷也可不偷（取各自较大的状态）
- 没有后效性 → 树形 DP，后序遍历自底向上汇总

状态定义（每个节点返回二元组 `(rob, not_rob)`）：
- `rob`：偷当前节点时的子树最大金额 = `node.val + left.not_rob + right.not_rob`
- `not_rob`：不偷当前节点时的子树最大金额 = `max(left.rob, left.not_rob) + max(right.rob, right.not_rob)`

根节点答案 = `max(root.rob, root.not_rob)`

## 解法一：递归 + 记忆化

### 思路

朴素递归对每个节点枚举“偷/不偷”会重复计算子树，用 `functools.lru_cache` 缓存以节点为参数的结果。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（哈希表 + 递归栈）

## 解法二：后序遍历 + 状态元组（推荐）

### 思路

每个节点直接返回 `(rob, not_rob)` 二元组，父节点据此推导自己的二元组。无需缓存、无需对节点哈希，一次后序遍历完成。

### 算法步骤

1. 递归遍历左子树，得到 `(left_rob, left_not)`
2. 递归遍历右子树，得到 `(right_rob, right_not)`
3. 当前节点：
   - `cur_rob = node.val + left_not + right_not`
   - `cur_not = max(left_rob, left_not) + max(right_rob, right_not)`
4. 返回 `(cur_rob, cur_not)`
5. 根节点：`max(rob, not_rob)`

### 复杂度分析

- 时间复杂度：O(n)（每个节点访问一次）
- 空间复杂度：O(h)（递归栈，h 为树高；最坏 O(n)）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 + 记忆化 | O(n) | O(n) | 需对节点哈希，常数较大 |
| 后序遍历 + 状态元组 | O(n) | O(h) | 无需哈希，推荐 |
