# 344.反转字符串 解题思路

## 问题分析

原地反转字符数组，O(1) 空间。最直观的方法是**双指针交换**：左右指针向中间靠拢，交换所指元素。

## 解法一：双指针交换（推荐）

### 算法步骤

1. `left = 0, right = n - 1`
2. while `left < right`：交换 `s[left]` 和 `s[right]`，`left++, right--`
3. 相遇时结束

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法二：异或交换

### 思路

不用临时变量，用异或交换两个元素：`a ^= b; b ^= a; a ^= b`。面试中偶有考察"不用额外空间交换"的 trick。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
