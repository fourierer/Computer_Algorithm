# 38.外观数列 解题思路

## 问题分析

每一项由前一项"描述"生成：统计连续相同字符的个数 + 字符本身。

关键点：
- 从 `n=1` 的 `"1"` 开始，迭代 `n-1` 次
- 每次遍历当前字符串，用双指针统计连续相同字符的段

## 解法一：迭代 + 双指针统计（推荐）

### 算法步骤

1. 初始 `s = "1"`
2. 重复 `n-1` 次：
   - 遍历 `s`，统计连续相同字符的个数 `count` 和字符 `c`
   - 拼接 `str(count) + c` 到新串
3. 返回 `s`

### 复杂度分析

- 时间复杂度：O(每项长度之和)，最长项约 2^30 但 n ≤ 30 实际可控
- 空间复杂度：O(当前项长度)
