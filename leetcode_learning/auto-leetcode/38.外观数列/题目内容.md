# 38.外观数列

- 难度：中等
- 题目链接：https://leetcode.cn/problems/count-and-say/

## 题目描述

「外观数列」是一个整数序列，从数字 1 开始，序列中的每一项都是对前一项的描述：

- `1` 被读作 "一个 1"，即 `11`
- `11` 被读作 "两个 1"，即 `21`
- `21` 被读作 "一个 2 一个 1"，即 `1211`
- 以此类推

给定一个正整数 `n`（1 ≤ n ≤ 30），输出外观数列的第 `n` 项。

## 示例

**示例 1：**
```
输入：n = 1
输出："1"
解释：基本情形。
```

**示例 2：**
```
输入：n = 4
输出："1211"
解释：
countAndSay(1) = "1"
countAndSay(2) = "11"
countAndSay(3) = "21"
countAndSay(4) = "1211"
```

## 提示

- `1 <= n <= 30`
