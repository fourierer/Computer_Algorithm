# 380.O(1)时间插入、删除和获取随机元素 解题思路

## 问题分析

关键洞察：
- 插入和删除 O(1) → 哈希表
- 随机获取 O(1) → 数组（支持按索引随机访问）
- 但数组删除 O(1) 需要技巧：**交换到末尾再删除**

我们需要**两个数据结构配合**：
- **数组** `vals`：存储所有元素，支持 O(1) 随机访问
- **哈希表** `idx`：键为元素值，值为在数组中的索引，支持 O(1) 查找

## 解法：哈希表 + 动态数组（推荐）

### 思路

**插入**：直接追加到数组末尾，哈希表记录索引。

**删除**：这是关键。不能直接从数组中间删除（O(n)），而是：
1. 用哈希表找到 `val` 在数组中的位置 `i`
2. 将数组末尾元素 `vals[-1]` 移到位置 `i`（覆盖要删除的元素）
3. 更新哈希表中 `vals[-1]` 的索引为 `i`
4. 删除数组末尾元素，删除哈希表中 `val` 的记录

这样删除操作就是 O(1)。

**随机获取**：生成随机索引，返回数组中对应元素。

### 算法步骤

**insert(val)：**
1. 若 `val` 在哈希表中，返回 `false`
2. 将 `val` 追加到数组末尾
3. `idx[val] = len(vals) - 1`
4. 返回 `true`

**remove(val)：**
1. 若 `val` 不在哈希表中，返回 `false`
2. `i = idx[val]`，`last = vals[-1]`
3. `vals[i] = last`（末尾元素覆盖要删除的元素）
4. `idx[last] = i`（更新末尾元素的索引）
5. 从数组删除末尾元素，从哈希表删除 `val`
6. 返回 `true`

**getRandom()：**
1. 生成 `[0, len(vals))` 范围内的随机索引
2. 返回 `vals[随机索引]`

### 复杂度分析

- insert：O(1)
- remove：O(1)
- getRandom：O(1)
- 空间复杂度：O(n)
