# 380.O(1)时间插入、删除和获取随机元素

- 难度：中等
- 题目链接：https://leetcode.cn/problems/insert-delete-getrandom-o1/

## 题目描述

实现 `RandomizedSet` 类：

- `bool insert(int val)` — 当元素 `val` 不存在时，向集合中插入该项，并返回 `true`；否则返回 `false`。
- `bool remove(int val)` — 当元素 `val` 存在时，从集合中移除该项，并返回 `true`；否则返回 `false`。
- `int getRandom()` — 随机返回现有集合中的一项。每个元素应该有相同的概率被返回。

你必须实现类的所有函数，且每个函数的**平均时间复杂度**为 **O(1)**。

## 示例

```
输入：
["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"]
[[], [1], [2], [2], [], [1], [2], []]

输出：
[null, true, false, true, 2, true, false, 2]

解释：
RandomizedSet randomSet = new RandomizedSet();
randomSet.insert(1);     // 向集合中插入 1，返回 true
randomSet.remove(2);     // 2 不在集合中，返回 false
randomSet.insert(2);      // 向集合中插入 2，返回 true，集合现在包含 [1,2]
randomSet.getRandom();    // getRandom 应随机返回 1 或 2
randomSet.remove(1);      // 从集合中移除 1，返回 true，集合现在包含 [2]
randomSet.insert(2);      // 2 已在集合中，返回 false
randomSet.getRandom();    // 由于集合中只有一个元素 2，getRandom 总是返回 2
```

## 提示

- `-2^31 <= val <= 2^31 - 1`
- `insert`、`remove` 和 `getRandom` 最多调用 `2 * 10^5` 次
- 调用 `getRandom` 时，集合中至少有一个元素
