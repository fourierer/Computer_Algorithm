# 383.赎金信 解题思路

## 问题分析

判断 `magazine` 中的字符是否足够拼出 `ransomNote`，即 `magazine` 中每个字符的出现次数是否 >= `ransomNote` 中对应字符的出现次数。本质上是比较两个字符串的字符频次。

## 解法一：哈希表计数（推荐）

### 思路

统计 `magazine` 中每个字符的出现次数，再遍历 `ransomNote` 逐个消耗，若某字符不够则返回 `False`。

### 算法步骤

1. 统计 `magazine` 中每个字符的出现次数
2. 遍历 `ransomNote`，对每个字符减少计数
3. 若某字符计数不足，返回 `False`
4. 遍历结束返回 `True`

### 复杂度分析

- 时间复杂度：O(m + n)，遍历两个字符串各一次
- 空间复杂度：O(∣Σ∣) = O(26) = O(1)，只有小写字母

## 解法二：数组计数

### 思路

由于只有小写字母，用长度为 26 的数组代替哈希表，效率更高。

### 复杂度分析

- 时间复杂度：O(m + n)
- 空间复杂度：O(26) = O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 哈希表计数 | O(m+n) | O(∣Σ∣) | 通用，适用于任意字符集 |
| 数组计数 | O(m+n) | O(1) | 常数更小，仅限小写字母 |
