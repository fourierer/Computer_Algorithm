# 394.字符串解码 解题思路

## 问题分析

嵌套结构 → 用**栈**处理。

关键点：
- 遇到 `[`：将当前字符串和重复次数压栈，重置临时变量
- 遇到 `]`：弹出栈顶的字符串和次数，将当前字符串重复后拼接到栈顶字符串
- 遇到数字：累积多位数字
- 遇到字母：累积到当前字符串

## 解法一：栈（推荐）

### 算法步骤

1. 维护 `cur_str`（当前层字符串）、`cur_num`（当前重复次数）、`stack`（存 `(prev_str, num)`）
2. 遍历字符：
   - 数字 → `cur_num = cur_num * 10 + int(c)`
   - `[` → 压栈 `(cur_str, cur_num)`，重置 `cur_str='', cur_num=0`
   - `]` → 弹出 `(prev_str, num)`，`cur_str = prev_str + cur_str * num`
   - 字母 → `cur_str += c`
3. 返回 `cur_str`

### 复杂度分析

- 时间复杂度：O(解码后字符串长度)
- 空间复杂度：O(嵌套深度 + 解码后长度)
