# 394.字符串解码

- 难度：中等
- 题目链接：https://leetcode.cn/problems/decode-string/

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为 `k[encoded_string]`，表示其中 `encoded_string` 重复 `k` 次。`k` 保证为正整数。输入字符串保证合法，且括号可以嵌套。

## 示例

**示例 1：**
```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**
```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**
```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

## 提示

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是有效的输入
