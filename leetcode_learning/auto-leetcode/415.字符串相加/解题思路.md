# 415.字符串相加 解题思路

## 问题分析

模拟手工加法：从最低位开始逐位相加，维护进位 `carry`。

关键点：
- 用 `ord(c) - ord('0')` 将字符转为数字，避免直接 int 转换
- 两个字符串长度可能不同，用索引从末尾向前，越界则按 0 处理
- 最后若 `carry > 0` 需要补最高位

## 解法一：双指针模拟（推荐）

### 算法步骤

1. `i, j` 分别指向 num1、num2 末尾，`carry = 0`
2. 循环直到两者都遍历完且 carry 为 0：
   - 取当前位数字（越界则 0）
   - `sum = d1 + d2 + carry`，`carry = sum // 10`，当前位 `= sum % 10`
   - 将当前位字符插入结果前部
3. 返回结果字符串

### 复杂度分析

- 时间复杂度：O(max(m, n))
- 空间复杂度：O(max(m, n))（结果字符串）
