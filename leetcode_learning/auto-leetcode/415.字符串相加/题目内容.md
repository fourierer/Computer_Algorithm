# 415.字符串相加

- 难度：简单
- 题目链接：https://leetcode.cn/problems/add-strings/

## 题目描述

给定两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和并同样以字符串形式返回。

你不能使用任何內建用于处理大整数的库（如 BigInteger），也不能直接将输入的字符串转换为整数形式。

## 示例

**示例 1：**
```
输入：num1 = "11", num2 = "123"
输出："134"
```

**示例 2：**
```
输入：num1 = "456", num2 = "77"
输出："533"
```

**示例 3：**
```
输入：num1 = "0", num2 = "0"
输出："0"
```

## 提示

- `1 <= num1.length, num2.length <= 10^4`
- `num1` 和 `num2` 只包含数字 `0-9`
- 不含前导零
