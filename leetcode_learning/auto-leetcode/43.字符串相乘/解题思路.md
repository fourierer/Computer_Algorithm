# 43.字符串相乘 解题思路

## 问题分析

模拟竖式乘法：`num1` 的第 `i` 位与 `num2` 的第 `j` 位相乘，结果落在最终乘积的第 `i+j` 和 `i+j+1` 位。

关键 trick（位置映射）：
- 设结果数组 `res` 长度为 `m + n`（两数乘积最多 m+n 位）
- `num1[i] * num2[j]` 的乘积 `p`（两位数）：
  - 低位 `p % 10` 累加到 `res[i + j + 1]`
  - 高位 `p // 10` 累加到 `res[i + j]`
- 全部累加完毕后，从后往前处理进位，再跳过前导零

## 解法一：位置映射 + 统一进位（推荐）

### 算法步骤

1. 创建 `res = [0] * (m + n)`
2. 双重循环：`res[i+j+1] += d1 * d2`（先累乘不进位）
3. 从右向左处理进位：`res[i-1] += res[i] // 10; res[i] %= 10`
4. 跳过前导零，转为字符串

### 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m + n)
