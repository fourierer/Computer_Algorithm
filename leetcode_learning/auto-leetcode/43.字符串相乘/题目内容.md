# 43.字符串相乘

- 难度：中等
- 题目链接：https://leetcode.cn/problems/multiply-strings/

## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 乘以 `num2` 的结果，也以字符串形式表示。

你不能使用任何标准库的大整数类型或直接将输入转换为整数。

## 示例

**示例 1：**
```
输入：num1 = "2", num2 = "3"
输出："6"
```

**示例 2：**
```
输入：num1 = "123", num2 = "456"
输出："56088"
```

## 提示

- `1 <= num1.length, num2.length <= 200`
- `num1` 和 `num2` 只含数字 `0-9`
- 不含前导零
