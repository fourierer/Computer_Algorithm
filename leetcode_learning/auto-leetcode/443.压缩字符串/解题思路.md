# 443.压缩字符串 解题思路

## 问题分析

原地压缩，用**双指针**：读指针扫描连续字符，写指针写入结果。

关键点：
- 写指针 `write` 记录写入位置
- 读指针 `read` 扫描连续相同字符的区间 `[anchor, read)`
- 写入字符后，若组长度 > 1，需将数字逐位写入（可能多位）

## 解法一：双指针原地压缩（推荐）

### 算法步骤

1. `write = 0`，`anchor = 0`（当前组起点）
2. `read` 从 0 遍历到 `n`（含 n，用于处理最后一组）：
   - 若 `read == n` 或 `chars[read] != chars[anchor]`：
     - 写入 `chars[anchor]` 到 `chars[write]`，`write++`
     - 组长度 `count = read - anchor`
     - 若 `count > 1`：将 `count` 的各位数字写入 `chars[write:]`，更新 `write`
     - `anchor = read`
3. 返回 `write`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（原地，数字拆分只占常数临时空间）
