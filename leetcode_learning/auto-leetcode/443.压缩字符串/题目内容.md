# 443.压缩字符串

- 难度：中等
- 题目链接：https://leetcode.cn/problems/string-compression/

## 题目描述

给你一个字符数组 `chars`，请使用下述算法压缩：

从空字符串 `s` 开始。对于 `chars` 中每组**连续重复字符**：
- 如果这一组长度为 1，则追加该字符到 `s`
- 否则追加该字符，再追加这一组的长度

压缩后的字符串不应返回，需要**原地修改**输入数组 `chars`，并返回新数组的长度。

## 示例

**示例 1：**
```
输入：chars = ["a","a","b","b","c","c","c"]
输出：返回 6，chars 的前 6 个字符为 ["a","2","b","2","c","3"]
```

**示例 2：**
```
输入：chars = ["a"]
输出：返回 1，chars 的前 1 个字符为 ["a"]
```

**示例 3：**
```
输入：chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
输出：返回 4，chars 的前 4 个字符为 ["a","b","1","2"]
```

## 提示

- `1 <= chars.length <= 2000`
- `chars[i]` 可以是小写英文字母、大写英文字母、数字或 `#`
