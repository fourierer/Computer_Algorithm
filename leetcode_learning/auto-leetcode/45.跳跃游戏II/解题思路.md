# 45.跳跃游戏II 解题思路

## 问题分析

关键洞察：
- 与第 55 题的区别：55 题问"能不能到达"，本题问"最少跳几步到达"
- 核心思想：**贪心 + 边界**。类似 BFS，每一"层"代表一步能到达的范围，遍历当前层的所有位置，求出下一步能到达的最远位置，到达边界时步数 +1，进入下一层

## 解法：贪心边界法

### 思路

维护三个变量：
- `rightmost`：当前能到达的最远位置（与第 55 题相同）
- `end`：当前这一步的边界，即这一步能到达的最远位置
- `step`：跳跃次数

遍历数组时（只到 n-2，因为到达最后一个位置不需要再跳）：
- 如果 `i <= rightmost`，更新 `rightmost = max(rightmost, i + nums[i])`
- 当 `i == end` 时，说明已遍历完当前这一步能到达的所有位置，必须再跳一步进入下一层，因此 `end = rightmost`，`step += 1`

为什么只遍历到 n-2？因为题目保证可以到达终点，当 `end >= n-1` 时已到达终点，不需要再跳。

### 算法步骤

1. `rightmost = 0`，`step = 0`，`end = 0`
2. 遍历 `i` 从 0 到 n-2：
   - 若 `i <= rightmost`：`rightmost = max(rightmost, i + nums[i])`
   - 若 `i == end`：抵达边界，`end = rightmost`，`step += 1`
3. 返回 `step`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
