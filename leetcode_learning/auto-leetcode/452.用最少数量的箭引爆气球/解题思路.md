# 452.用最少数量的箭引爆气球 解题思路

## 问题分析

求最少弓箭数等价于求最多能合并的**重叠区间组数**——一支箭能射爆所有与它重叠的气球。关键洞察：**按右端点排序，贪心地选择每个重叠组的右端点作为射箭位置，能让尽可能多的气球被同一支箭射爆**。

为什么按右端点排序而非左端点？按右端点排序后，遇到不重叠的气球时，之前的箭已经尽可能向右延伸，保证浪费最少。

## 解法一：贪心 + 按右端点排序（推荐）

### 思路

按右端点排序后，用一支箭从第一个气球的右端点射出。遍历过程中，若下一个气球的左端点大于当前箭的位置，说明不重叠，需要新箭；否则当前箭仍可射爆。

### 算法步骤

1. 按右端点对区间排序
2. 初始化箭数 `arrows = 1`，箭位置 `pos = points[0][1]`
3. 遍历区间：
   - 若 `points[i][0] > pos`，说明不重叠，需要新箭：`arrows += 1`，更新 `pos = points[i][1]`
   - 否则，当前箭可以继续射爆这个气球
4. 返回 `arrows`

### 复杂度分析

- 时间复杂度：O(n log n)，排序开销
- 空间复杂度：O(log n)，排序栈空间

## 解法二：贪心 + 按左端点排序

### 思路

按左端点排序，维护当前重叠区间的右边界。每次遇到新的区间，若左端点大于当前右边界，说明不重叠，需要新箭并更新右边界；否则缩小右边界为两者右端点的较小值（取交集）。

### 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(log n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 按右端点排序贪心 | O(n log n) | O(log n) | 逻辑更简洁，箭位置即为右端点 |
| 按左端点排序贪心 | O(n log n) | O(log n) | 需要维护交集右边界 |
