# 459.重复的子字符串 解题思路

## 问题分析

判断 `s` 是否能由子串重复构成。

经典 trick：**如果 `s` 由子串 `t` 重复构成，则 `s` 是 `s + s` 的子串（去掉首尾各一个字符后）**。

证明直觉：
- `s = t + t + ... + t`（k 次），则 `s + s` 中去掉首尾字符后，中间必然包含一个完整的 `s`（因为 `t` 的周期性，第二组 `s` 的前半和第一组 `s` 的后半能拼出一个 `s`）
- 反之若 `s` 不能由子串重复构成，则不会出现

## 解法一：拼接查找 trick（推荐）

### 算法步骤

1. 令 `t = s + s`
2. 去掉 `t` 的首尾各一个字符：`t = t[1:-1]`
3. 若 `s in t` 则返回 `True`，否则 `False`

### 复杂度分析

- 时间复杂度：O(n)（字符串查找）
- 空间复杂度：O(n)

## 解法二：KMP next 数组

### 思路

计算 `s` 的 next 数组（最长相等前后缀长度），若 `n % (n - next[n-1] - 1) == 0` 且 `next[n-1] > 0` 则可重复。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)
