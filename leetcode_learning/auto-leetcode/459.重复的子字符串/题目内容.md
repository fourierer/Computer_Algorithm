# 459.重复的子字符串

- 难度：中等
- 题目链接：https://leetcode.cn/problems/repeated-substring-pattern/

## 题目描述

给定一个非空的字符串 `s`，检查它是否可以由它的一个子串重复多次构成。

## 示例

**示例 1：**
```
输入：s = "abab"
输出：true
解释：可以由子串 "ab" 重复 2 次构成。
```

**示例 2：**
```
输入：s = "aba"
输出：false
```

**示例 3：**
```
输入：s = "abcabcabcabc"
输出：true
解释：可以由子串 "abc" 重复 4 次构成。
```

## 提示

- `1 <= s.length <= 10^4`
- `s` 由小写英文字母组成
