# 48.旋转图像 解题思路

## 问题分析

将 n×n 矩阵顺时针旋转 90°，要求原地操作。关键观察：旋转 90° 等价于**先沿水平翻转，再沿主对角线翻转**。

证明：对于位置 `(i, j)`：
- 水平翻转：`(i, j) → (n-1-i, j)`
- 主对角线翻转：`(n-1-i, j) → (j, n-1-i)`
- 结果 `j, n-1-i` 正好是顺时针旋转 90° 后的位置

## 解法一：水平翻转 + 主对角线翻转（推荐）

### 思路

分两步完成旋转：先沿水平中线上下翻转，再沿主对角线翻转。每一步都是原地交换元素。

### 算法步骤

1. 水平翻转：交换 `matrix[i][j]` 和 `matrix[n-1-i][j]`（i 从 0 到 n/2）
2. 主对角线翻转：交换 `matrix[i][j]` 和 `matrix[j][i]`（i 从 0 到 n，j 从 0 到 i）

### 复杂度分析

- 时间复杂度：O(n²)，遍历矩阵两次
- 空间复杂度：O(1)，原地交换

## 解法二：直接旋转四角

### 思路

每次将四个对应位置的元素同时旋转交换：`(i,j) → (j,n-1-i) → (n-1-i,n-1-j) → (n-1-j,i) → (i,j)`。

### 算法步骤

1. 遍历外层 `i` 从 0 到 n/2，内层 `j` 从 `i` 到 `n-1-i-1`
2. 用临时变量保存一个元素，按逆时针方向依次赋值：
   - `temp = matrix[i][j]`
   - `matrix[i][j] = matrix[n-1-j][i]`
   - `matrix[n-1-j][i] = matrix[n-1-i][n-1-j]`
   - `matrix[n-1-i][n-1-j] = matrix[j][n-1-i]`
   - `matrix[j][n-1-i] = temp`

### 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 水平翻转+对角线翻转 | O(n²) | O(1) | 两步清晰，不易出错 |
| 直接旋转四角 | O(n²) | O(1) | 一次完成，下标易混淆 |
