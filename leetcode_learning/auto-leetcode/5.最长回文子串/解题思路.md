# 5.最长回文子串 解题思路

## 问题分析

在字符串中找出最长的回文子串。回文具有天然的递推性质：若 `s[i+1..j-1]` 是回文且 `s[i] == s[j]`，则 `s[i..j]` 也是回文。这恰好适合动态规划。

## 解法：动态规划

### 思路

用 `dp[i][j]` 表示子串 `s[i..j]` 是否为回文。利用回文的递推关系，按子串长度（间隔 k）从小到大填充 dp 表，同时记录最长回文子串。

**关键点：** 循环顺序必须以间隔 k 为外层循环，而非 i。因为 `dp[i][j]` 依赖 `dp[i+1][j-1]`，若按常规 i、j 循环，`dp[i+1][j-1]` 尚未计算，会得到错误结果。

### 算法步骤

1. 初始化 `dp` 为 n×n 全 0 矩阵，`result_str = ''`
2. 按间隔 `k` 从 0 到 n-1 循环：
   - 对每个 `i`，`j = i + k`：
     - `k == 0`（单字符）：`dp[i][j] = 1`
     - `k == 1`（相邻两字符）：`dp[i][j] = (s[i] == s[j])`
     - `k > 1`：`dp[i][j] = (s[i] == s[j]) and dp[i+1][j-1]`
   - 若 `dp[i][j]` 为 True 且当前长度超过 `result_str`，更新 `result_str = s[i:j+1]`
3. 返回 `result_str`

### 复杂度分析

- 时间复杂度：O(n²)，需填充 n² 规模的 dp 表
- 空间复杂度：O(n²)，dp 矩阵

### 补充

代码中还包含 `lengthOfLongestSubsequence` 方法，用于求无重复字符的最长子序列（不要求连续），答案即为不同字符的数量 `len(set(s))`。
