# 50.Pow(x, n) 解题思路

## 问题分析

关键洞察：
- 直接循环乘 n 次，时间复杂度 O(n)，n 很大时会超时
- 快速幂：利用 `x^n = (x^(n/2))²` 的性质，将时间复杂度降到 O(log n)

## 快速幂的数学原理

- 若 n 为偶数：`x^n = (x^(n/2))²`
- 若 n 为奇数：`x^n = (x^((n-1)/2))² × x`

每次将问题规模减半，递归深度为 O(log n)。

例如 `x^10 = (x^5)²`，而 `x^5 = (x^2)² × x`：

```
x^10 = (x^5)²
x^5 = (x^2)² × x
x^2 = (x^1)²
x^1 = (x^0)² × x
x^0 = 1
```

## 解法一：递归快速幂（推荐）

### 思路

递归计算 `x^(N//2)`，根据 N 的奇偶性决定是否多乘一个 x。

负数指数：`x^(-n) = 1 / x^n`。

### 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(log n)，递归栈深度

## 解法二：迭代快速幂

### 思路

将 n 的二进制表示逐位处理，从最低位到最高位：
- 若当前位为 1，将当前的 `x_contribution` 乘入结果
- 每移一位，`x_contribution` 自乘（平方）

例如 `x^10, 10 = 1010₂`：
- 第 0 位 = 0：不乘
- 第 1 位 = 1：乘 `x²`
- 第 2 位 = 0：不乘
- 第 3 位 = 1：乘 `x⁸`
- 结果 = `x² × x⁸ = x^10`

### 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)，无递归栈

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归快速幂 | O(log n) | O(log n) | 直观，有递归栈开销 |
| 迭代快速幂 | O(log n) | O(1) | 空间更优 |
