# 54.螺旋矩阵 解题思路

## 问题分析

按顺时针螺旋顺序遍历矩阵所有元素，即依次从左到右、从上到下、从右到左、从下到上，逐层向内收缩。

核心在于维护四个边界（上、下、左、右），每遍历完一条边就收缩对应边界，直到所有元素遍历完毕。

## 解法一：边界模拟（推荐）

### 思路

用四个变量 `top`、`bottom`、`left`、`right` 表示当前未遍历区域的边界。按"右→下→左→上"的顺序逐边遍历，每完成一条边收缩对应边界。

### 算法步骤

1. 初始化 `top = 0`，`bottom = m - 1`，`left = 0`，`right = n - 1`
2. 循环遍历，直到所有元素都被访问：
   - 从左到右遍历上边界，`top += 1`
   - 从上到下遍历右边界，`right -= 1`
   - 若 `top <= bottom`，从右到左遍历下边界，`bottom -= 1`
   - 若 `left <= right`，从下到上遍历左边界，`left += 1`
3. 注意：遍历下边界和左边界前需检查边界是否有效，避免单行/单列时重复遍历

### 复杂度分析

- 时间复杂度：O(m × n)，每个元素访问一次
- 空间复杂度：O(1)，只使用四个边界变量（不计返回值空间）

## 解法二：方向数组模拟

### 思路

用方向数组表示四个移动方向（右、下、左、上），每遇到边界或已访问格子时改变方向。

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)，需要额外标记已访问格子

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 边界模拟 | O(m×n) | O(1) | 代码简洁，面试首选 |
| 方向数组模拟 | O(m×n) | O(m×n) | 通用但空间开销大 |
