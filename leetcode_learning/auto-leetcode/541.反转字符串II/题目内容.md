# 541.反转字符串II

- 难度：简单
- 题目链接：https://leetcode.cn/problems/reverse-string-ii/

## 题目描述

给定一个字符串 `s` 和一个整数 `k`，从字符串开头每 `2k` 个字符为一组，反转前 `k` 个字符。

- 如果剩余字符少于 `k` 个，则将剩余字符全部反转。
- 如果剩余字符在 `[k, 2k)` 之间，则反转前 `k` 个，其余保持不变。

## 示例

**示例 1：**
```
输入：s = "abcdefg", k = 2
输出："bacdfeg"
```

**示例 2：**
```
输入：s = "abcd", k = 2
输出："bacd"
```

## 提示

- `1 <= s.length <= 10^4`
- `s` 仅由小写英文组成
- `1 <= k <= 10^4`
