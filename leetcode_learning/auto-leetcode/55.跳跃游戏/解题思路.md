# 55.跳跃游戏 解题思路

## 问题分析

关键洞察：
- 问题不是"怎么跳最优"，而是"能不能到达终点"
- 只需维护一个**最远可达位置** `rightmost`，逐步扩展它
- 从左到右遍历，只有当前位置 `i` 可达（`i <= rightmost`）时，才更新 `rightmost`

## 解法：贪心

### 思路

维护变量 `rightmost` 表示当前能到达的最远位置。遍历数组时：
- 如果 `i <= rightmost`，说明位置 `i` 可达，更新 `rightmost = max(rightmost, i + nums[i])`
- 如果 `i > rightmost`，说明当前位置不可达，跳过（不更新 `rightmost`）
- 如果 `rightmost >= n - 1`，说明可以到达终点，直接返回 `true`

最终如果遍历完仍 `rightmost < n - 1`，返回 `false`。

### 算法步骤

1. `rightmost = 0`
2. 遍历 `i` 从 0 到 n-1：
   - 若 `i <= rightmost`：`rightmost = max(rightmost, i + nums[i])`
   - 若 `rightmost >= n - 1`：返回 `true`
3. 返回 `false`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
