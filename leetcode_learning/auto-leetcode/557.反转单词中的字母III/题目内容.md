# 557.反转单词中的字母III

- 难度：简单
- 题目链接：https://leetcode.cn/problems/reverse-words-in-a-string-iii/

## 题目描述

给定一个字符串 `s`，你需要反转字符串中每个单词的字符顺序，同时仍保留空格和单词的初始顺序。

## 示例

**示例 1：**
```
输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"
```

**示例 2：**
```
输入：s = "God Ding"
输出："doG gniD"
```

## 提示

- `1 <= s.length <= 5 * 10^4`
- `s` 包含可打印的 ASCII 字符
- `s` 不包含前导或尾随空格
- `s` 中至少存在一个单词
- 单词间用单个空格分隔
