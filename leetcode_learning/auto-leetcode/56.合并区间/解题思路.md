# 56.合并区间 解题思路

## 问题分析

合并所有重叠区间。关键洞察：**按左端点排序后，重叠的区间一定相邻**。排序后只需逐个判断当前区间与结果中最后一个区间是否重叠即可。

两个区间 `[a,b]` 和 `[c,d]` 重叠的条件：`c <= b`（因为已排序，所以 `a <= c` 一定成立）。

## 解法一：排序 + 一次遍历（推荐）

### 思路

先按左端点排序，然后维护一个结果列表。遍历每个区间，若与结果中最后一个区间重叠则合并（更新右端点为较大值），否则直接加入结果。

### 算法步骤

1. 按 `start_i` 对区间排序
2. 初始化结果列表 `merged`，将第一个区间加入
3. 遍历剩余区间，对每个区间 `[start, end]`：
   - 若 `start <= merged[-1][1]`，说明与最后一个区间重叠，合并：`merged[-1][1] = max(merged[-1][1], end)`
   - 否则，将当前区间加入 `merged`
4. 返回 `merged`

### 复杂度分析

- 时间复杂度：O(n log n)，排序开销
- 空间复杂度：O(n)，存储结果（若原地修改则为 O(log n) 排序栈空间）

## 解法二：排序 + 原地修改

### 思路

直接在原数组上原地合并，用指针 `i` 指向当前合并结果的位置，省去额外列表。

### 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(log n)，排序栈空间

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 排序 + 新列表 | O(n log n) | O(n) | 逻辑清晰，面试首选 |
| 排序 + 原地修改 | O(n log n) | O(log n) | 空间更优，但会修改原数组 |
