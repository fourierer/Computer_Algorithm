# 57.插入区间 解题思路

## 问题分析

在已排序的无重叠区间列表中插入一个新区间，并合并所有重叠区间。关键洞察：**将区间分为三段处理**——完全在新区间左侧的、与新区间重叠的、完全在新区间右侧的。

## 解法一：三段式遍历（推荐）

### 思路

遍历区间列表，按与 `newInterval` 的位置关系分三步处理：
1. 左侧：区间右端点小于新区间左端点，直接加入结果
2. 重叠：区间与新区间有交集，合并（更新新区间左右端点）
3. 右侧：区间左端点大于新区间右端点，直接加入结果

### 算法步骤

1. 初始化结果列表 `result`
2. 将所有**在新区间左侧**的区间（`interval[1] < newInterval[0]`）直接加入 `result`
3. 将所有**与新区间重叠**的区间（`interval[0] <= newInterval[1]`）合并入 `newInterval`：
   - `newInterval[0] = min(newInterval[0], interval[0])`
   - `newInterval[1] = max(newInterval[1], interval[1])`
4. 将合并后的 `newInterval` 加入 `result`
5. 将剩余区间加入 `result`
6. 返回 `result`

### 复杂度分析

- 时间复杂度：O(n)，遍历一次
- 空间复杂度：O(n)，存储结果

## 解法二：先插入再合并

### 思路

先将新区间插入列表，再按合并区间的方法排序+合并。

### 复杂度分析

- 时间复杂度：O(n log n)，需要排序
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 三段式遍历 | O(n) | O(n) | 利用已排序性质，一次遍历 |
| 先插入再合并 | O(n log n) | O(n) | 复用合并区间逻辑，但有排序开销 |
