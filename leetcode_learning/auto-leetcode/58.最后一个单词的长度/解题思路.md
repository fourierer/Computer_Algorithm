# 58.最后一个单词的长度 解题思路

## 问题分析

求字符串中最后一个单词的长度。关键问题在于：字符串末尾可能有多个空格，需要跳过尾部空格后，再从后往前计数直到遇到空格或字符串开头。

## 解法一：调用内置函数

### 思路

使用 `split()` 将字符串按空格分割为单词列表，直接取最后一个单词的长度。简单直接，但 `split()` 会遍历整个字符串，且需要额外空间存储所有单词。

### 算法步骤

1. 调用 `s.split()` 按空格分割（自动忽略连续空格）
2. 取列表最后一个元素并返回其长度

### 复杂度分析

- 时间复杂度：O(n)，需要遍历整个字符串
- 空间复杂度：O(n)，`split()` 生成所有单词的列表

## 解法二：逆序遍历（推荐）

### 思路

从字符串末尾开始向前遍历，先跳过尾部空格，然后逐个计数非空格字符，直到遇到空格或到达字符串开头。只需一次遍历，且不需要额外空间。

### 算法步骤

1. 从字符串末尾 `n-1` 开始，跳过所有尾部空格
2. 从去掉尾部空格后的位置继续向前遍历，每遇到非空格字符则计数 +1
3. 遇到空格则停止，返回计数结果
4. 若遍历到字符串开头仍未遇到空格，同样返回计数结果

### 复杂度分析

- 时间复杂度：O(n)，最坏情况遍历整个字符串
- 空间复杂度：O(1)，只使用常量级额外变量

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 调用内置函数 | O(n) | O(n) | 代码简洁，但空间开销大 |
| 逆序遍历 | O(n) | O(1) | 空间最优，原地计算 |
