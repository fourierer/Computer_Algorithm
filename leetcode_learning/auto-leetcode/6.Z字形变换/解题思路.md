# 6.Z字形变换 解题思路

## 问题分析

将字符串按 Z 字形（锯齿形）排列后逐行读取。关键是模拟字符在 Z 字形矩阵中的填充过程：先竖直向下，再斜向右上，循环往复。

每个完整的 Z 字形周期长度为 `t = 2 * numRows - 2`（竖直列 `numRows` 个字符 + 斜线 `numRows - 2` 个字符）。

## 解法一：模拟矩阵填充（推荐）

### 思路

创建二维矩阵模拟 Z 字形排列过程。用坐标 `(x, y)` 跟踪当前填充位置：竖直段向下移动（x 递增），斜线段向右上移动（x 递减，y 递增）。最后逐行拼接非空字符。

### 算法步骤

1. 特判：若行数为 1 或行数 >= 字符串长度，直接返回原串
2. 计算周期 `t = numRows * 2 - 2`，列数 `c = (n + t - 1) // t * (numRows - 1)`
3. 初始化 `numRows × c` 的矩阵
4. 遍历字符串，根据当前索引在周期中的位置决定移动方向：
   - `i % t < numRows - 1`：竖直段，x 递增
   - 否则：斜线段，x 递减、y 递增
5. 逐行拼接矩阵中非空字符

### 复杂度分析

- 时间复杂度：O(n)，遍历一次填充，再遍历矩阵拼接
- 空间复杂度：O(n)，矩阵存储

## 解法二：按行直接拼接

### 思路

不模拟矩阵，直接按行计算每个字符最终所在的行。对于第 `r` 行的字符，其在原字符串中的下标满足周期规律，可以直接推导。

### 算法步骤

1. 特判同上
2. 对每一行 `r`（0 到 numRows-1），遍历所有周期起点，计算该行在每周期中的字符下标
3. 行 0 和行 numRows-1 每周期只有 1 个字符，中间行每周期有 2 个字符
4. 按行顺序拼接所有字符

### 复杂度分析

- 时间复杂度：O(n)，每个字符恰好被访问一次
- 空间复杂度：O(n)，存储结果字符串

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 模拟矩阵填充 | O(n) | O(n) | 直观易理解，面试首选 |
| 按行直接拼接 | O(n) | O(n) | 空间常数更优，无需矩阵 |
