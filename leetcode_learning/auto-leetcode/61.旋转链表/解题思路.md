# 61. 旋转链表 - 解题思路

## 问题分析

将链表向右旋转 k 步，等价于把链表末尾 k % n 个节点移到头部。k 可能远大于链表长度，因此需要取模。

## 解法：闭合为环 + 定位断点

### 思路

1. 先遍历链表求出长度 n，同时找到尾节点
2. 取模 `k = k % n`，若为 0 直接返回
3. 将尾节点指向头节点，形成环
4. 新的尾节点是从头节点出发走 `n - k` 步的位置
5. 新的头节点是新尾节点的下一个节点，断开环即可

### 算法步骤（伪代码）

```
n = 1, cur = head
while cur.next != null:
    cur = cur.next, n += 1

add = n - k % n
if add == n: return head

cur.next = head          // 闭合为环
while add > 0:
    cur = cur.next, add -= 1

ret = cur.next           // 新头节点
cur.next = null          // 断开环
return ret
```

### 复杂度分析

- **时间复杂度**：O(n)，遍历链表两次
- **空间复杂度**：O(1)，只使用常数额外空间

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 闭合为环 | O(n) | O(1) | 推荐，简洁高效 |
| 快慢指针 | O(n) | O(1) | 两次遍历，思路类似 |
| 数组辅助 | O(n) | O(n) | 额外空间，不推荐 |
