# 63.不同路径II 解题思路

## 问题分析

关键洞察：
- 与 62 题（不同路径）的区别在于网格中存在障碍物
- 障碍物处路径数为 0（无法通过），其余位置仍由上方和左方路径数相加
- `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，但障碍物处 `dp[i][j] = 0`

## 边界条件特别注意

第一行和第一列只有一种到达方式（从左边或从上方），但只要遇到障碍物，该位置及其之后的所有位置路径数都变为 0：
- 第一行：`dp[0][j] = dp[0][j-1]`（若 `obstacleGrid[0][j] == 0`），否则为 0
- 第一列：`dp[i][0] = dp[i-1][0]`（若 `obstacleGrid[i][0] == 0`），否则为 0

因为一旦某个格子是障碍物，后面同行的格子就无法从左边到达，后面同列的格子也无法从上面到达。

起点若为障碍物，直接返回 0。

## 解法：二维 DP

### 算法步骤

1. `dp[0][0] = 1`（若起点非障碍物），否则 `dp[0][0] = 0`
2. 初始化第一列和第一行
3. 双层循环计算中间位置：非障碍物处 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，障碍物处保持 0
4. 返回 `dp[n-1][m-1]`

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)
