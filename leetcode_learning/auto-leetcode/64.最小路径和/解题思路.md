# 64.最小路径和 解题思路

## 问题分析

关键洞察：
- 只能向下或向右移动，每个格子只能从上方或左方到达
- 定义 `dp[i][j]` 为从左上角到 `(i, j)` 的最小路径和
- 状态转移：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`

## 边界条件

- 第一行：只能从左边到达，`dp[0][j] = dp[0][j-1] + grid[0][j]`
- 第一列：只能从上边到达，`dp[i][0] = dp[i-1][0] + grid[i][0]`
- 左上角：`dp[0][0] = grid[0][0]`

## 解法一：二维 DP（推荐）

### 算法步骤

1. `dp[0][0] = grid[0][0]`
2. 初始化第一行和第一列的边界值
3. 双层循环计算中间位置：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`
4. 返回 `dp[rows-1][columns-1]`

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 解法二：原地修改

### 思路

直接在 `grid` 上修改，不需要额外 DP 数组，空间优化到 O(1)（不计输出空间）。

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(1)（原地修改 grid）

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二维 DP | O(m×n) | O(m×n) | 直观易懂，不修改原数组 |
| 原地修改 | O(m×n) | O(1) | 空间最优，但修改了原数组 |
