# 66.加一 解题思路

## 问题分析

关键洞察：
- 模拟手工加法：从末尾开始加 1，若当前位不是 9，直接加 1 返回；若是 9，变 0 并向前进位
- 只需要关注"进位链"，即从末尾开始连续的 9

## 解法一：从后往前遍历（推荐）

### 思路

从最后一位开始往前遍历：
- 若当前位不是 9：加 1，并把后面所有位（都是 9，已经变成 0 的进位链）置 0，直接返回
- 若当前位是 9：进位，继续往前看

如果所有位都是 9（如 `[9,9,9]`），循环结束后返回 `[1] + [0] * n`（即 `[1,0,0,0]`）。

### 算法步骤

1. 从后往前遍历 `i = n-1, n-2, ..., 0`
2. 若 `digits[i] != 9`：`digits[i] += 1`，将 `i+1..n-1` 全部置 0，返回
3. 若 `digits[i] == 9`：进位，继续循环
4. 循环结束仍有进位：返回 `[1] + [0] * n`

### 复杂度分析

- 时间复杂度：O(n)，最坏遍历整个数组
- 空间复杂度：O(1)，原地修改（除了全 9 的情况需要新数组）
