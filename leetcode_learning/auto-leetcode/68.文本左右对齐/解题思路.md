# 68.文本左右对齐 解题思路

## 问题分析

将一组单词按左对齐+右对齐（两端对齐）规则排版为最多 `maxWidth` 个字符的行。核心在于：
1. 贪心地确定每行能放多少单词
2. 根据行类型（普通行 / 单词行 / 最后一行）分配空格

空格分配的关键规则：
- 普通行：空格尽量均匀分配，左侧空格数 >= 右侧
- 只有一个单词的行：左对齐，末尾补空格
- 最后一行：左对齐，单词间只有一个空格，末尾补空格

## 解法一：贪心模拟（推荐）

### 思路

逐行处理：先贪心确定每行能容纳的单词数，再根据行类型分配空格。空格分配时，先将总空格数均分给每个间隔，余数则从左到右每个间隔多分配一个。

### 算法步骤

1. 用双指针 `left`/`right` 确定当前行的单词范围，累计单词长度 + 最少空格数 <= maxWidth
2. 若是最后一行：单词间仅一个空格，末尾补齐
3. 若当前行只有一个单词：左对齐，末尾补空格
4. 若当前行有多个单词：
   - 计算空格总数 `numSpaces = maxWidth - sumLen`
   - 每个间隔基础空格 `avgSpaces = numSpaces // (numWords - 1)`
   - 余数 `extraSpaces`：前 `extraSpaces` 个间隔各多一个空格
   - 拼接时分为两部分：前 `extraSpaces + 1` 个单词（间隔多一个空格）和剩余单词

### 复杂度分析

- 时间复杂度：O(n)，每个单词只被访问一次
- 空间复杂度：O(n)，存储结果
