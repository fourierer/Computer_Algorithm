# 69.x的平方根 解题思路

## 问题分析

关键洞察：
- 求 √x 的整数部分，即找最大的整数 `ans` 满足 `ans² ≤ x`
- 本质是在有序范围内查找，可用二分查找
- 也可用牛顿迭代法快速逼近实数平方根

## 解法一：牛顿迭代法（推荐）

### 思路

求 √x 等价于求 f(t) = t² - x = 0 的正根。

### 牛顿迭代公式推导

核心思想：用**切线**逐步逼近函数的零点。

设当前猜测值为 `t_n`，对应曲线上的点 `(t_n, f(t_n))`：
1. 在该点作曲线的切线，切线斜率 = 导数 `f'(t_n) = 2 * t_n`
2. 切线方程（点斜式）：`y - f(t_n) = f'(t_n) * (t - t_n)`
3. 求切线与 x 轴的交点 `t_{n+1}`（令 `y = 0`）：
   - `0 - f(t_n) = f'(t_n) * (t_{n+1} - t_n)`
   - `t_{n+1} = t_n - f(t_n) / f'(t_n)`
4. 代入 `f(t) = t² - x`，`f'(t) = 2t`：
   - `t_{n+1} = t_n - (t_n² - x) / (2 * t_n) = (t_n + x / t_n) / 2`

**几何直觉**：`t_n` 处的切线与 x 轴的交点 `t_{n+1}` 比 `t_n` 更接近真正的零点 √x，反复用切线逼近即可收敛。

初始值取 `t_0 = x`，迭代直到收敛（两次结果差值小于阈值），最后取整数部分。

### 为什么初始值取 x？

因为 √x ≤ x（x ≥ 1 时），从 x 开始迭代保证逐步逼近，收敛速度是二次的（每次有效位数翻倍）。

### 算法步骤

1. 特判 `x == 0` 返回 0
2. 初始化 `x0 = x`（初始猜测值）
3. 计算 `xi = 0.5 * (x0 + C / x0)`，其中 `C = x`
4. 若 `|x0 - xi| < 1e-5`，停止迭代
5. 否则 `x0 = xi`，继续迭代
6. 返回 `int(x0)`

### 复杂度分析

- 时间复杂度：O(log x)，牛顿迭代二次收敛
- 空间复杂度：O(1)

## 解法二：二分查找

### 思路

在 `[0, x]` 范围内二分查找最大的 `mid` 使得 `mid² ≤ x`。

### 算法步骤

1. `left, right = 0, x`
2. while `left <= right`：
   - `mid = left + (right - left) // 2`
   - 若 `mid² <= x`：记录 `ans = mid`，`left = mid + 1`
   - 若 `mid² > x`：`right = mid - 1`
3. 返回 `ans`

### 复杂度分析

- 时间复杂度：O(log x)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 牛顿迭代 | O(log x) | O(1) | 收敛更快，代码简洁 |
| 二分查找 | O(log x) | O(1) | 直观易懂 |
