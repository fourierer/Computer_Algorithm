# 69.x的平方根

- 难度：简单
- 题目链接：https://leetcode.cn/problems/sqrtx/

## 题目描述

给你一个非负整数 `x`，计算并返回 `x` 的**算术平方根**的整数部分。

注意：不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

## 示例

**示例 1：**
```
输入：x = 4
输出：2
```

**示例 2：**
```
输入：x = 8
输出：2
解释：8 的算术平方根是 2.828...，整数部分为 2。
```

## 提示

- `0 <= x <= 2^31 - 1`
