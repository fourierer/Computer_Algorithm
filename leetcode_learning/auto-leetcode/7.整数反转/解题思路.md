# 7.整数反转 解题思路

## 问题分析

将 32 位有符号整数逐位反转，若反转后溢出则返回 0。核心难点在于负数取模的行为：Python 中 `-123 % 10 = 7`（余数总为正），与 C/Java 等语言不同，因此必须分开处理正负数。

## 解法一：分正负逐位反转（代码实际采用）

### 思路

对正数直接逐位取模拼接反转；对负数先取绝对值做同样操作，最后再加负号。反转完成后检查 32 位整数范围 `[-2^31, 2^31-1]`，溢出则返回 0。

### 算法步骤

1. 若 `x > 0`：
   - 循环：`temp = x % 10`，`sum = sum * 10 + temp`，`x //= 10`
   - 检查溢出，返回 `sum` 或 0
2. 若 `x < 0`：
   - 取绝对值 `y = -x`
   - 同上逐位反转得到 `sum`
   - `sum_minus = -sum`，检查溢出，返回 `sum_minus` 或 0
3. 若 `x == 0`：返回 0

### 复杂度分析

- 时间复杂度：O(n)，n 为数字的位数
- 空间复杂度：O(1)

## 解法二：统一取模反转（未验证思路）

### 思路

不区分正负，直接对 x 逐位取模拼接。Python 中负数取模结果为正，循环结束后 `sum` 始终为正，只需对负数取反即可。更简洁但需注意语言差异。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法三：字符串反转（未验证思路）

### 思路

将整数转为字符串，用切片 `[::-1]` 反转后转回整数。负数先去掉负号反转再加回。最简洁但依赖字符串操作。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，需存储字符串
