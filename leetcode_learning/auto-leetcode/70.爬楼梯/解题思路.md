# 70.爬楼梯 解题思路

## 问题分析

关键洞察：
- 到达第 n 阶只有两种来源：从第 n-1 阶爬 1 步，或从第 n-2 阶爬 2 步
- 因此 `dp[n] = dp[n-1] + dp[n-2]`，本质就是斐波那契数列

## 解法一：动态规划（推荐）

### 思路

定义 `dp[i]` 为爬到第 i 阶的方法数。

边界条件：
- `dp[1] = 1`：只有一种方法（爬 1 步）
- `dp[2] = 2`：两种方法（1+1 或 2）

状态转移：`dp[i] = dp[i-1] + dp[i-2]`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法二：空间优化（滚动变量）

### 思路

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，用两个变量滚动即可，空间优化到 O(1)。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 动态规划 | O(n) | O(n) | 直观易懂 |
| 滚动变量 | O(n) | O(1) | 空间最优 |
