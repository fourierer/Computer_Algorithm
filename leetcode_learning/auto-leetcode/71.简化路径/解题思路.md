# 71.简化路径 解题思路

## 问题分析

将 Unix 风格绝对路径转为规范路径。关键洞察：**用栈模拟路径层级**——遇到目录名入栈，遇到 `..` 出栈，遇到 `.` 和空串忽略，最终用 `/` 拼接栈中元素即可。

## 解法一：栈（推荐）

### 思路

先将路径按 `/` 分割，然后逐个处理每个部分：
- 空串或 `.`：忽略（无操作）
- `..`：出栈（返回上级目录，需判断栈非空）
- 其他：入栈（有效目录名）

最后用 `/` 拼接栈中元素，前面加上根目录的 `/`。

### 算法步骤

1. 将 `path` 按 `/` 分割得到各部分
2. 初始化空栈 `stack`
3. 遍历每个部分 `part`：
   - 若 `part` 为空或 `.`，跳过
   - 若 `part` 为 `..`，弹栈（栈非空时）
   - 否则，将 `part` 入栈
4. 返回 `"/" + "/".join(stack)` ，若栈为空则返回 `"/"`

### 复杂度分析

- 时间复杂度：O(n)，遍历路径一次
- 空间复杂度：O(n)，栈存储目录名

## 解法二：原地数组模拟栈

### 思路

用列表本身模拟栈操作，逻辑完全相同，只是写法略有不同。

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 栈 | O(n) | O(n) | 逻辑清晰，面试首选 |
| 原地数组模拟栈 | O(n) | O(n) | 写法略有不同，本质相同 |
