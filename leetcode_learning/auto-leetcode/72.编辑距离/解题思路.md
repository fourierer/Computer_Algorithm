# 72.编辑距离 解题思路

## 问题分析

关键洞察：
- 将 `word1` 转换成 `word2`，每一步只能执行插入、删除、替换三种操作之一
- 典型二维动态规划问题，子问题为：`word1` 的前 `i` 个字符转换成 `word2` 的前 `j` 个字符的最少操作数

## 解法一：二维 DP（推荐）

### 思路

定义 `dp[i][j]` 为 `word1[:i]` 转换成 `word2[:j]` 的最少操作数。

DP 表尺寸为 `(m+1) × (n+1)`，因为 `i` 取值范围是 `0..m`（0 表示空串，m 表示完整 word1），`j` 取值范围是 `0..n`（同理）。如果不 +1，就没有行/列来存储空串的边界情况，递推也就缺少初始值。

边界条件：
- `dp[i][0] = i`：`word1` 的前 `i` 个字符变成空串，需要删除 `i` 次
- `dp[0][j] = j`：空串变成 `word2` 的前 `j` 个字符，需要插入 `j` 次

状态转移：
- 若 `word1[i-1] == word2[j-1]`：末尾字符相同，无需操作，`dp[i][j] = dp[i-1][j-1]`
- 若 `word1[i-1] != word2[j-1]`：取三种操作的最小值
  - 替换：`dp[i-1][j-1] + 1`（把 `word1[i-1]` 替换为 `word2[j-1]`）
  - 插入：`dp[i][j-1] + 1`（在 `word1` 末尾插入 `word2[j-1]`）
  - 删除：`dp[i-1][j] + 1`（删除 `word1[i-1]`）

### 算法步骤

1. 初始化 `(m+1) × (n+1)` 的 DP 表，填入边界条件
2. 双层循环遍历 `i=1..m, j=1..n`
3. 若字符相同，直接取左上角值；否则取三个方向最小值 +1
4. 返回 `dp[m][n]`

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 二维 DP | O(m×n) | O(m×n) | 直观易懂，经典解法 |
| 一维 DP 滚动 | O(m×n) | O(n) | 空间优化，仅保留上一行 |
