# 73.矩阵置零 解题思路

## 问题分析

将矩阵中所有 0 所在行和列的元素都置为 0。难点在于**原地操作**：如果直接修改，会丢失原始 0 的信息，导致整行整列被错误置零。

## 解法一：O(m+n) 额外空间

### 思路

用两个数组分别记录哪些行和列需要置零，第二次遍历时统一修改。

### 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m + n)

## 解法二：O(1) 原地标记（推荐）

### 思路

复用矩阵的第一行和第一列作为标记数组，避免额外空间。需要额外两个变量标记第一行和第一列本身是否有 0。

### 算法步骤

1. 用 `first_row_zero` 和 `first_col_zero` 标记第一行和第一列是否有 0
2. 遍历矩阵（除第一行第一列），若 `matrix[i][j] == 0`，则标记 `matrix[i][0] = 0` 和 `matrix[0][j] = 0`
3. 根据标记更新矩阵（从内到外，避免覆盖标记）：
   - 若 `matrix[i][0] == 0`，第 i 行全置 0
   - 若 `matrix[0][j] == 0`，第 j 列全置 0
4. 最后根据 `first_row_zero` 和 `first_col_zero` 处理第一行和第一列

### 复杂度分析

- 时间复杂度：O(m × n)，遍历矩阵两次
- 空间复杂度：O(1)，仅使用两个布尔变量

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 额外数组 | O(m×n) | O(m+n) | 简单直观 |
| 原地标记 | O(m×n) | O(1) | 最优解，面试首选 |
