# 76.最小覆盖子串 解题思路

## 问题分析

在 `s` 中找最短的子串，使其包含 `t` 的所有字符（含重复）。这是经典的滑动窗口问题：先扩展右端点直到窗口满足条件，再收缩左端点寻找更短子串。

关键点：用一个变量 `formed` 记录当前窗口已满足的字符种类数，避免每次都遍历哈希表检查。

## 解法一：滑动窗口（推荐）

### 思路

1. 用哈希表 `need` 统计 `t` 中每个字符的需要数量
2. 用哈希表 `window` 统计当前窗口中各字符的数量
3. 扩展右端点，当窗口满足所有字符需求时，收缩左端点找最短子串

### 算法步骤

1. 统计 `t` 中各字符的需求 `need`，记录需要的字符种类数 `need_count`
2. 初始化 `left = 0`，`formed = 0`（已满足的字符种类数），`window` 为空哈希表
3. 遍历 `right` 从 0 到 `len(s)-1`：
   - 将 `s[right]` 加入 `window`
   - 若该字符数量刚好满足需求，`formed += 1`
   - 当 `formed == need_count` 时，尝试收缩左端点：
     - 更新最短子串的起始位置和长度
     - 将 `s[left]` 从 `window` 中减少
     - 若减少后不满足需求，`formed -= 1`
     - `left += 1`
4. 返回最短子串（若未找到则返回空串）

### 复杂度分析

- 时间复杂度：O(m + n)，左右指针各遍历一次
- 空间复杂度：O(∣Σ∣)，`Σ` 为字符集大小，最多 52 个英文字母

## 解法二：优化滑动窗口

### 思路

只遍历 `s` 中出现在 `t` 里的字符，跳过无关字符，减少无效遍历。先将 `s` 中属于 `t` 的字符及其下标提取为列表，再对该列表做滑动窗口。

### 复杂度分析

- 时间复杂度：O(m + n)，最坏情况与解法一相同，但常数更优
- 空间复杂度：O(m)，存储过滤后的字符列表

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 滑动窗口 | O(m+n) | O(∣Σ∣) | 经典写法，面试首选 |
| 优化滑动窗口 | O(m+n) | O(m) | 跳过无关字符，常数更优 |
