# 763.划分字母区间 解题思路

## 问题分析

目标：划分**尽可能多**的片段，且每个字母只出现在一个片段中。

关键洞察：
- 一个片段的**右边界**必须延伸到该片段内所有字母的**最后一次出现位置**的最远点
- 否则，存在某个字母在片段外再次出现，违反“只在一个片段中”的约束
- 这等价于“区间合并”思想：每个字母对应一个区间 `[首次出现, 最后出现]`，相交的区间必须合并到同一片段

### 贪心策略（一次扫描）

维护当前段的右边界 `end`：
- 扫描到位置 `i` 时，`end = max(end, last[s[i]])`
- 当 `i == end`，说明当前段内所有字母的最后一次出现都已覆盖 → 可以在此切分
- 记录当前段长度，开始新的一段

## 解法一：贪心 + 最后出现位置表（推荐）

### 算法步骤

1. 预处理：遍历 `s` 记录每个字母的**最后一次出现位置** `last[c]`
2. 扫描 `s`，维护 `start`（当前段起点）、`end`（当前段右边界）：
   - `end = max(end, last[s[i]])`
   - 若 `i == end`：记录 `end - start + 1`，并令 `start = i + 1` 开始新段
3. 返回所有段长度

### 复杂度分析

- 时间复杂度：O(n)，两趟扫描
- 空间复杂度：O(|Σ|)，字母表大小（小写字母为 26）

## 解法二：区间合并

### 思路

将每个字母映射为区间 `[first, last]`，按起点排序后合并相交区间，输出每段长度。

### 复杂度分析

- 时间复杂度：O(n + |Σ| log |Σ|)
- 空间复杂度：O(|Σ|)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 贪心 + 最后出现表 | O(n) | O(|Σ|) | 推荐，一次扫描简洁高效 |
| 区间合并 | O(n + |Σ| log |Σ|) | O(|Σ|) | 思路通用但需排序 |
