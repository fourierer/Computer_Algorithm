# 763.划分字母区间

- 难度：中等
- 题目链接：https://leetcode.cn/problems/partition-labels/

## 题目描述

给你一个字符串 `s`。我们要把这个字符串划分为**尽可能多**的片段，使得：

- 每个片段中的字母只出现在该片段中，不出现在其它片段中（即同一字母的所有出现都必须落在同一个片段内）。
- 将所有片段按顺序连接起来，得到的字符串等于原字符串 `s`。

返回一个列表，表示每个划分片段的长度。

## 示例

**示例 1：**
```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij"。
每个字母只出现在一个片段中。
像 "ababcbacadefegde" 和 "hijhklij" 这种划分是错误的，因为片段数更少。
```

**示例 2：**
```
输入：s = "eccbbbbbab"
输出：[1,2,7]
解释：划分结果为 "e"、"cc"、"bbbbbab"。
字母 c 只在第二段出现，字母 b 只在第三段出现，字母 e 只在第一段出现。
```

## 提示

- `1 <= s.length <= 500`
- `s` 由小写英文字母组成
