# 8.字符串转换整数(atoi) 解题思路

## 问题分析

核心是状态机：空格 → 符号 → 数字。难点在于**溢出截断**的边界处理。

关键 trick（避免 long）：在累加过程中**提前判断溢出**，而非算完再截断：
- 正数：若 `res > INT_MAX // 10`，或 `res == INT_MAX // 10` 且当前位 `> 7`，直接返回 `INT_MAX`
- 负数：同理，当前位 `> 8` 时返回 `INT_MIN`

## 解法一：逐字符状态机 + 提前判溢出（推荐）

### 算法步骤

1. 跳过前导空格
2. 读取正负号
3. 逐位读数字，每步判断溢出并截断返回
4. 返回 `sign * res`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
