# 82. 删除排序链表中的重复元素 II

**难度**：中等

**题目描述**：

给定一个已排序的链表的头 `head`，删除所有重复的节点，使得每个数字只出现一次。返回删除后的链表。

**注意**：与 83 题不同，本题要求将所有出现过重复的节点全部删除，而不是保留一个。

**示例 1**：

```
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

**示例 2**：

```
输入：head = [1,1,1,2,3]
输出：[2,3]
```

**约束条件**：

- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序排列
