# 83. 删除排序链表中的重复元素 - 解题思路

## 问题分析

已排序链表中，重复元素必然相邻。本题要求**保留一个**重复节点，与 82 题（全部删除）不同。

## 解法：一次遍历

### 思路

1. 用指针 `cur` 从 `head` 开始遍历
2. 比较 `cur.val` 与 `cur.next.val`，若相等则跳过 `cur.next`（`cur.next = cur.next.next`）
3. 若不相等，`cur` 正常后移
4. 返回 `head`（头节点不会被删除）

### 算法步骤（伪代码）

```
cur = head
while cur.next != null:
    if cur.val == cur.next.val:
        cur.next = cur.next.next
    else:
        cur = cur.next
return head
```

### 复杂度分析

- **时间复杂度**：O(n)，每个节点最多访问一次
- **空间复杂度**：O(1)，只使用常数额外空间

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 一次遍历 | O(n) | O(1) | 推荐，简洁高效 |
| 递归 | O(n) | O(n) | 思路清晰但空间开销大 |
| 哈希表 | O(n) | O(n) | 不利用已排序特性，空间浪费 |
