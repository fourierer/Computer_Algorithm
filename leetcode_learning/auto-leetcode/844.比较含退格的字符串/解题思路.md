# 844.比较含退格的字符串 解题思路

## 问题分析

`#` 是退格，需要"跳过"前一个字符。

### 解法一：栈重建
用栈模拟，遇 `#` 弹栈，否则入栈。简单但空间 O(n)。

### 解法二：双指针逆序（推荐，O(1) 空间）
从字符串末尾向前遍历，遇到 `#` 记录退格数，跳过相应数量的字符。

关键 trick：**从后往前**，因为退格只影响前面的字符。

## 解法二算法步骤

1. `i, j` 指向两串末尾，`skip_i, skip_j` 记录待跳过的字符数
2. 循环直到两串都遍历完：
   - 对 `s`：若 `#` 则 `skip_i++`，`i--`；若 `skip_i > 0` 则跳过；否则找到有效字符
   - 对 `t` 同理
   - 比较当前有效字符，不同则 `False`
3. 两串同时遍历完则 `True`

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)
