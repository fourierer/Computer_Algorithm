# 86.分隔链表 解题思路

## 问题分析

本题要求将链表按照给定值 `x` 分成两部分：小于 `x` 的节点在前，大于或等于 `x` 的节点在后，且两部分内部的相对顺序不变。

**关键洞察：** 这本质上是一个链表的"稳定划分"问题。我们需要维护两个子链表，分别收集满足条件的节点，最后将两个子链表拼接起来。

## 解法一：双指针 / 双链表（推荐）

### 思路

使用两个哑节点（dummy node）分别作为"小于链表"和"大于等于链表"的头指针。遍历原链表，将每个节点按条件追加到对应链表中。遍历结束后，将"小于链表"的尾部连接到"大于等于链表"的头部，并确保"大于等于链表"的尾部指向 `None`，防止形成环。

### 算法步骤

1. 创建两个哑节点 `before_head` 和 `after_head`，分别用于构建小于链表和大于等于链表
2. 用 `before` 和 `after` 两个指针分别指向两个链表的当前尾部
3. 遍历原链表：
   - 若当前节点值 `< x`，将其接到 `before` 后面，`before` 前进一步
   - 否则，将其接到 `after` 后面，`after` 前进一步
4. 将 `after.next` 置为 `None`（断开可能的环）
5. 将 `before.next` 连接到 `after_head.next`（拼接两个链表）
6. 返回 `before_head.next`

### 复杂度分析

- 时间复杂度：O(n)，其中 n 是链表长度，只需遍历一次
- 空间复杂度：O(1)，只使用了常数个指针变量

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 双链表拼接 | O(n) | O(1) | 最优解，一次遍历，原地操作 |
| 收集值再重建 | O(n) | O(n) | 需要额外数组存储值，不够优雅 |
