# 88.合并两个有序数组 解题思路

## 问题分析

关键洞察：
- `nums1` 尾部有 `n` 个空位，正好可以容纳 `nums2` 的所有元素
- 如果从前往后合并，需要额外空间暂存被覆盖的元素
- **从后往前填充**可以避免覆盖问题——末尾空位就是我们要填充的位置

## 解法一：合并后排序

### 思路

先将 `nums2` 全部复制到 `nums1` 的尾部，再整体排序。

### 算法步骤

1. 将 `nums2` 的元素复制到 `nums1[m:]`
2. 对 `nums1` 排序

### 复杂度分析

- 时间复杂度：O((m+n) log(m+n))
- 空间复杂度：O(1)（取决于排序算法）

## 解法二：双指针从后往前（推荐）

### 思路

利用 `nums1` 尾部的空位，从后往前比较两个数组的最大值，将较大的放到 `nums1` 末尾。这样每次填充的都是空位或不再需要的元素，不会覆盖待比较的数据。

### 算法步骤

1. 初始化三个指针：`i = m - 1`（nums1 有效末尾）、`j = n - 1`（nums2 末尾）、`k = m + n - 1`（合并结果末尾）
2. 当 `i >= 0` 且 `j >= 0` 时：
   - 若 `nums1[i] > nums2[j]`：`nums1[k] = nums1[i]`，`i -= 1`
   - 否则：`nums1[k] = nums2[j]`，`j -= 1`
   - `k -= 1`
3. 若 `j >= 0`（nums2 还有剩余），将剩余元素复制到 `nums1` 前部
4. 若 `i >= 0`（nums1 还有剩余），无需处理（已在正确位置）

### 复杂度分析

- 时间复杂度：O(m + n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 合并后排序 | O((m+n)log(m+n)) | O(1) | 简单但未利用有序性 |
| 双指针从后往前 | O(m+n) | O(1) | 最优解，利用有序性原地合并 |
