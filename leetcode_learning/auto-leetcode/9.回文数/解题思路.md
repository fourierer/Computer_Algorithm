# 9.回文数 解题思路

## 问题分析

回文数的核心特征是数字正反读一致。需要特别处理：
- 负数一定不是回文数（有负号）
- 个位为 0 的非零数不是回文数（如 10 → 01）

## 解法一：字符串双指针

### 思路

将整数转为字符串，用首尾双指针逐步向中间靠拢，逐位比较是否相同。

### 算法步骤

1. 负数直接返回 False
2. 将整数转为字符串 `str_x`
3. 初始化左指针 `i = 0`，右指针 `j = len(str_x) - 1`
4. 当 `i < j` 时：
   - 若 `str_x[i] != str_x[j]`，返回 False
   - 否则 `i += 1`，`j -= 1`
5. 循环结束返回 True

### 复杂度分析

- 时间复杂度：O(n)，n 为数字的位数
- 空间复杂度：O(n)，需要存储字符串

## 解法二：整数完全反转（代码实际采用）

### 思路

通过数学运算将整个整数反转（逐位取模拼接），再与原数比较是否相等。用 `store_x` 保存原始值，因为 `x` 在反转过程中会被逐步消耗。

### 算法步骤

1. 负数直接返回 False
2. 保存原数 `store_x = x`
3. 初始化反转数 `flip_x = 0`
4. 循环：当 `x != 0` 时
   - 取末位 `mod = x % 10`
   - 追加到反转数 `flip_x = flip_x * 10 + mod`
   - 去掉末位 `x //= 10`
5. 返回 `flip_x == store_x`

### 复杂度分析

- 时间复杂度：O(n)，n 为数字的位数
- 空间复杂度：O(1)

### 注意

此解法将整个数字反转，当数字很大时反转结果可能溢出（Python 中整数无溢出问题，但在 C/Java 等语言中需注意）。若需避免溢出，可改为只反转一半数字再比较。
