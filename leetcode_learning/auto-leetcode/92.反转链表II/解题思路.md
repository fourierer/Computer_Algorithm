# 92.反转链表II 解题思路

## 问题分析

反转链表中 `[left, right]` 区间的节点。关键洞察：**头插法**——用 `pre` 指向反转区间的前一个节点，每次将 `cur.next` 插到 `pre.next` 的位置，逐步完成反转。这样只需一趟遍历，且不需要额外空间存储反转后的链表。

## 反转过程图示

以 `1 -> 2 -> 3 -> 4 -> 5`，left=2，right=4 为例：

```
初始：pre=1, cur=2
第1次：1 -> 3 -> 2 -> 4 -> 5  （把3插到pre后面）
第2次：1 -> 4 -> 3 -> 2 -> 5  （把4插到pre后面）
```

每次循环：将 `cur.next`（待反转节点）插到 `pre.next` 位置。`cur` 始终指向反转区间的第一个节点（值不变，但位置后移）。

## 解法一：头插法（推荐）

### 思路

1. 用 `dummy_node` 保护头节点，避免 left=1 的边界情况
2. `pre` 移动到反转区间前一个节点
3. `cur` 指向反转区间第一个节点
4. 每次将 `cur.next` 头插到 `pre` 后面，循环 `right - left` 次

### 算法步骤

1. 创建 `dummy_node`，指向 `head`
2. `pre` 向右走 `left - 1` 步，到达反转区间前一个节点
3. `cur = pre.next`
4. 循环 `right - left` 次：
   - `next = cur.next`（待反转节点）
   - `cur.next = next.next`（cur 跳过 next）
   - `next.next = pre.next`（next 指向反转区间当前头）
   - `pre.next = next`（next 成为新的反转区间头）
5. 返回 `dummy_node.next`

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 头插法 | O(n) | O(1) | 一趟扫描，面试首选 |
