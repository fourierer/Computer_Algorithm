# 93.复原IP地址 解题思路

## 问题分析

将字符串分成 4 段，每段满足：
- 值在 0~255
- 无前导零（除非段本身是 "0"）
- 长度 1~3

回溯：在当前切分位置尝试切 1/2/3 位，合法则继续切下一段。

## 解法一：回溯（推荐）

### 算法步骤

1. 回溯参数：`start`（当前起始位置）、`path`（已切的段列表）
2. 若 `len(path) == 4`：
   - 若 `start == n`，将 `path` 用 `.` 拼接加入结果
   - 否则不合法，返回
3. 尝试切 `l = 1, 2, 3` 位：
   - 越界跳过
   - 前导零（长度 > 1 且首字符为 '0'）跳过
   - 值 > 255 跳过
   - 合法则加入 path 递归 `start + l`，回溯
4. 剪枝：剩余字符数必须在 `[4 - len(path) - 1, 3 * (4 - len(path))]` 范围内

### 复杂度分析

- 时间复杂度：O(3^4)（每段最多 3 种切法，共 4 段，常数级）
- 空间复杂度：O(4)（递归栈）
