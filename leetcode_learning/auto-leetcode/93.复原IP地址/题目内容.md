# 93.复原IP地址

- 难度：中等
- 题目链接：https://leetcode.cn/problems/restore-ip-addresses/

## 题目描述

有效 IP 地址 正好由四个整数组成（每个整数位于 `0` 到 `255` 之间，不含前导零），整数之间用 `'.'` 分隔。例如 `"255.255.255.111"` 和 `"192.168.1.1"` 是有效 IP，但 `"255.255.255.011"`、`"255.255.255.256"` 和 `"192.168.1.312"` 是无效 IP。

给定一个**只包含数字**的字符串 `s`，用来表示可能的 IP 地址，返回所有有效的 IP 地址（可以由 `s` 中插入 `'.'` 来构成）。你不能重新排序或删除 `s` 中的任何数字，可以改变 `s` 的顺序。

## 示例

**示例 1：**
```
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

**示例 2：**
```
输入：s = "0000"
输出：["0.0.0.0"]
```

**示例 3：**
```
输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
```

## 提示

- `1 <= s.length <= 20`
- `s` 仅由数字组成
