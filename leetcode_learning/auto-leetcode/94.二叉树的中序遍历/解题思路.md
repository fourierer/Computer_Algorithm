# 94.二叉树的中序遍历 解题思路

## 问题分析

中序遍历顺序：**左 → 根 → 右**。需要同时掌握递归和迭代两种实现方式。

## 解法一：递归（DFS）

### 思路

定义递归函数 `traverse(node)`：
1. 若节点为空，返回
2. 递归遍历左子树
3. 访问当前节点（加入结果）
4. 递归遍历右子树

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树的高度（递归栈）

## 解法二：迭代（栈模拟）

### 思路

中序遍历的迭代比前序复杂，因为需要先一路向左走到底，再回溯访问根节点和右子树。

### 算法步骤

1. 初始化空栈和当前节点 `curr = root`
2. 当 `curr` 不为空或栈不为空时：
   - 一路向左：将 `curr` 及其所有左子节点依次入栈，`curr = curr.left`
   - 弹出栈顶节点，访问它
   - 转向右子树：`curr = node.right`
3. 返回结果

### 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈最多存储树的高度个节点

## 解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 递归 | O(n) | O(h) | 代码简洁，面试首选 |
| 迭代 | O(n) | O(n) | 一路向左入栈，回溯时访问 |
