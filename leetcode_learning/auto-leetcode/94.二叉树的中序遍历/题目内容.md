# 94.二叉树的中序遍历

- 难度：简单
- 题目链接：https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 题目描述

给定一个二叉树的根节点 `root`，返回它的 **中序** 遍历。

中序遍历顺序：左子树 → 根节点 → 右子树

## 示例

**示例 1：**
```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [1]
输出：[1]
```

## 提示

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`
