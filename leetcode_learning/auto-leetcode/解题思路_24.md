# 解题思路

## 题目分析

- **问题类型**：链表 / 指针操作
- **关键约束**：不能修改节点值，只能交换节点；节点数 ≤ 100
- **核心难点**：交换两个节点时需要正确处理三组指针关系（前驱、两个节点、后继）

## 思路一：迭代（推荐）

### 核心思想

用虚拟头结点 + 三个指针，每次交换相邻两个节点，然后前移继续。

### 交换操作拆解

交换节点 `a` 和 `b`（`a` 在前，`b` 在后），需要四个指针参与：

```
交换前：prev → a → b → b.next

步骤1: prev.next = b        # prev 指向 b（b 变成新的第一个）
步骤2: a.next = b.next      # a 指向 b 的后继（a 变成新的第二个）
步骤3: b.next = a           # b 指向 a（完成交换）

交换后：prev → b → a → b.next(原)
```

### 图示

```
原始：dummy → 1 → 2 → 3 → 4 → None

第1轮交换 (prev=dummy, a=1, b=2)：
  dummy → 2 → 1 → 3 → 4 → None
  prev 移到 1

第2轮交换 (prev=1, a=3, b=4)：
  dummy → 2 → 1 → 4 → 3 → None
  prev 移到 3

结束（3.next 为 None）
结果：2 → 1 → 4 → 3
```

### 复杂度

- 时间：$O(n)$
- 空间：$O(1)$

## 思路二：递归

### 核心思想

交换前两个节点，然后递归处理剩余部分。

### 递推关系

```
swapPairs(head):
  1. head 和 head.next 交换
  2. head.next = swapPairs(交换后的剩余部分)
  3. 返回新的头节点（原 head.next）
```

### 图示

```
swapPairs(1→2→3→4)
  交换 1 和 2 → 2→1 + swapPairs(3→4)
                              交换 3 和 4 → 4→3 + swapPairs(None)
                                                      return None
                              return 4→3
  1.next = 4→3
  return 2→1→4→3
```

### 复杂度

- 时间：$O(n)$
- 空间：$O(n)$（递归栈）

## 两种方法对比

| 方法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| 迭代 | $O(n)$ | $O(1)$ | 推荐，无栈开销 |
| 递归 | $O(n)$ | $O(n)$ | 代码简洁，思路优雅 |
